LINUX + 0x2E3BE0에서 유효한 장치 트리(DTB)의 헤더와 속성을 파싱했다. 루트 compatible에는 milbeaut,sc2000a 및 socionext,milbeaut-evb가 들어 있다. 모델명은 Socionext SC2000A EVB w/ RTOS and NETSEC, Linux에 기술된 CPU 노드는 /cpus/cpu@3이고 호환 문자열은 arm,cortex-a7이다. 커널 내장 설정에도 CONFIG_ARCH_MILBEAUT=y가 있다. 첨부 펌웨어의 Linux가 Socionext Milbeaut SC2000A 계열과 Cortex-A7을 대상으로 한다는 직접 증거다. 검증 코드 · DTB 포맷

리코는 K-3 II의 영상 엔진을 PRIME III, K-3 Mark III의 영상 엔진과 가속기를 PRIME V 및 2세대 accelerator unit으로 구분한다. Socionext는 SC2000을 Milbeaut M10V 계열의 쿼드 Cortex-A7 제품으로 설명한다. K-3 Mark III 전용 독립 분석도 이 계열을 지목한다. 리코 공개 커널에는 R03010 보드와 GR III 보드의 설정 파일이 함께 있다. 이 자료는 플랫폼 공유의 근거지만, 두 카메라의 펌웨어·보드가 동일하다거나 K-3 II의 모든 하위 시스템이 교체됐다고 판단할 근거는 부족하다. 실장 패키지의 각인, 카메라의 실동작 클럭 및 별도 가속기의 부품번호는 미확인이다. 리코 K-3 II · 리코 K-3 Mark III · Socionext SC2000 사양 · akinas의 K-3 Mark III 분석

Python 3 표준 라이브러리만 사용한다. 첫 명령의 출력 폴더는 새 경로여야 한다. 펌웨어 파일을 읽을 수 있는 위치에서 다음을 실행한다.

python inspect_firmware.py fwdc233b.bin --output-dir .private/my-decode
python verify_findings.py .private/my-decode/decoded.bin

첫 명령은 decoded.bin과 블록별 원본·출력 매핑을 담은 inventory.json을 저장한다. 두 번째 명령은 이 버전의 디코딩 결과 SHA-256을 검사한 뒤 DTB, 커널 설정, 초기 파일시스템, 공개 셸 원문, UART·HDMI 함수 범위를 검증한다. 입력 파일 없이 도구 자체를 점검하려면 두 스크립트에 각각 --self-test를 전달한다.

자동 디컴파일까지 재현하려면 별도 Python 환경에 angr==10.0.5를 설치한다. 아래 명령은 원본 RTOS 해시와 함수 범위를 검사한 뒤 디컴파일러의 C 형태 출력을 표준 출력으로 보낸다. 디컴파일 경고는 표준 오류에 표시된다.

python decompile_sample.py .private/my-decode/decoded.bin hdmi
python decompile_sample.py .private/my-decode/decoded.bin register-write

REA는 배포 ZIP과 구성원의 해시를 확인하는 데 사용했다. Windows의 REA 펌웨어 스캐너는 Linux Binwalk 공급자가 필요해 실행되지 않았다. 위의 압축 해제·커널 심볼 복원·함수 분석은 각각 별도 도구로 수행했다. 리코의 펌웨어 사용 약관 3·4·6항에는 복제·역분석·양도 제한이 명시되어 있다. 이 저장소의 공개 범위는 재배포 조건을 확인한 OSS 파일, 직접 작성한 분석 도구와 측정 결과다. 원본 BIN, 추출한 독점 코드, RTOS 디컴파일 출력은 로컬에만 보관했다. 카메라 플래싱, 실기 실행, 전체 펌웨어 재빌드는 수행하지 않았다. 리코 배포 약관 · 커널 심볼 복원 도구 · angr 디컴파일러

원본 펌웨어·추출 계수·디컴파일 C 원문은 로컬에 보관한다. 정적 분석과 합성 실행 결과를 실제 카메라의 픽셀 출력 검증과 구분한다.
