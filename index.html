PENTAX K-3 Mark III · 펌웨어 2.20

K-3 Mark III 펌웨어 안을 들여다본 기록

리코가 배포한 펌웨어 파일 하나를 풀어, 카메라가 어떻게 부팅하고 사진의 색을 만들고 초점을 맞추고 메뉴를 그리는지 코드 수준에서 추적했습니다. 무엇을 알아냈고 무엇은 아직 모르는지 근거와 함께 적었습니다.

먼저 알아 둘 점

모든 분석은 PC에서 했습니다. 수정한 펌웨어를 카메라에 설치하거나 실행한 적이 없습니다. 이 저장소에는 카메라에 넣을 수 있는 펌웨어가 없으며, 원본 펌웨어와 제조사 코드도 들어 있지 않습니다.

이 연구가 답하려는 네 가지 질문

세 기종(K-3 Mark III, K-3 II, Q7)을 같은 질문으로 조사하고 있습니다. 아래는 K-3 Mark III에서 지금까지 온 지점입니다. 세 기종을 나란히 비교한 표는 세 기종 연구 본부에 있습니다.

  • 목표 1

    펌웨어를 고쳐서 다시 만들 수 있는가

    파일을 다시 만드는 단계까지 확인

    알아낸 것
    아무것도 바꾸지 않고 다시 포장하면 배포본과 바이트까지 같습니다. 색 행렬 함수 하나를 C로 다시 짜서 넣은 후보 파일은 원본 코드의 헤더·체크섬 검사를 통과했습니다.
    아직 모르는 것
    카메라가 이 파일을 업데이트로 받아들이는지, 부팅하는지. 부팅 단계의 인증 여부.
  • 목표 2

    Lightroom에서 카메라의 색을 낼 수 있는가

    시험 프로파일을 실제 Lightroom에 적용

    알아낸 것
    카메라 안에서 색 모드에 따라 행렬과 감마가 어떻게 달라지는지 추적했습니다. 시험용 색 프로파일(DCP)을 만들어 Lightroom Classic에서 실제 TIFF를 내보냈습니다.
    아직 모르는 것
    카메라 JPEG와 얼마나 가까운지. 색 차이를 잰 것은 K-3 II의 RAW 한 장뿐입니다.
  • 목표 3

    AF 동작을 바꿀 수 있는가

    제어 코드를 읽는 기초 단계

    알아낸 것
    AF 계산의 기본 연산, 렌즈가 알려 주는 능력에 따라 구동 방식을 고르는 분기, AF 요청이 큐를 거쳐 완료 통지로 이어지는 흐름을 원본 코드로 확인했습니다.
    아직 모르는 것
    실제 렌즈와의 통신, 모터 이동, 초점 정확도. 코드를 바꿔 본 적은 없습니다.
  • 목표 4

    이 카메라의 화면을 다른 기종에 옮길 수 있는가

    첫 대상 화면을 분석한 단계

    알아낸 것
    색공간 선택 화면의 선택·확정·취소와 방향 입력 처리, 아이콘 자원의 저장 형식을 확인했습니다.
    아직 모르는 것
    실제 버튼 입력에서 LCD 출력까지의 연결. 다른 기종으로 옮기는 작업은 시작하지 않았습니다.

펌웨어 파일 안에 든 것

배포 파일 fwdc233b.bin은 압축되어 있습니다. 풀면 이름이 붙은 덩어리(레코드) 15개가 차례로 나옵니다. 아래 막대는 압축을 푼 뒤의 크기 비율입니다.

  • 35,106,716바이트배포 파일 크기
  • 78,683,892바이트압축을 푼 크기 (3,202블록)
  • 15개이름이 붙은 레코드
  • 957개RTOS 셸 명령
  • Cortex-A7Linux 장치 트리에 적힌 CPU

카메라 안의 두 운영체제

이 카메라의 주 프로세서에서는 프로그램 두 벌이 함께 돕니다. 사진을 찍는 일은 RTOS가, 통신은 Linux가 맡는 구조로 읽힙니다.

  • RTOS — 촬영, AF, 영상 처리, 메뉴. 이 연구의 대부분이 여기를 다룹니다.
  • Linux — 시작 스크립트에 무선 드라이버, USB·MTP, 네트워크·블루투스, 웹 API 서비스를 띄우는 순서가 적혀 있습니다.
  • M0 · BOOT — 전원이 켜진 직후 저장소와 메모리를 준비하고 RTOS를 올리는 초기 단계입니다.

Linux 쪽은 파일에 적힌 내용을 읽은 것이며, 실제 부팅 로그를 수집한 것은 아닙니다.

어떤 칩인가

Linux 장치 트리에는 milbeaut,sc2000a와 arm,cortex-a7이 적혀 있습니다. Socionext의 영상 처리용 칩 Milbeaut SC2000A 계열을 대상으로 만든 펌웨어라는 직접 증거입니다. 리코는 이 카메라의 영상 엔진을 PRIME V라고 부릅니다.

실제 기판에 붙은 칩의 각인, 동작 클럭, 별도 가속 장치의 부품 번호는 확인하지 못했습니다.

검증 수준 읽는 법

모든 문서는 결과마다 “얼마나 확실한가”를 같은 네 가지 표시로 구분합니다. 표시가 다르면 믿을 수 있는 정도가 다릅니다.

  • 확인

    원본 펌웨어의 기계어를 PC의 CPU 에뮬레이터에서 실제로 실행해 관측했거나, 파일의 바이트를 직접 읽어 구조와 해시를 대조한 결과입니다.

  • 정적 분석

    코드를 실행하지 않고, 기계어를 사람이 읽을 수 있게 바꾼 결과를 읽어서 판단한 내용입니다.

  • 모델

    하드웨어의 응답이나 입력 데이터처럼, 실물 대신 연구자가 정해서 넣은 값입니다. 그 조건에서만 성립합니다.

  • 미확인

    아직 확인하지 못했거나, 실물 카메라가 있어야 확인할 수 있는 내용입니다.

Lightroom 색 프로파일 실험만은 성격이 다릅니다. 실제 RAW 파일을 실제 Adobe Lightroom Classic에 넣어 얻은 측정값입니다. 다만 그것도 Lightroom의 출력을 잰 것이지 카메라 안의 처리를 잰 것은 아닙니다.
