sRGB 글자 전송의 화면 경계

K-3 III 펌웨어 2.20의 비회전 텍스트 전송은 두 사각형을 먼저 교차시킵니다. 76×40 sRGB 마스크를 일곱 좌표에서 그려 소스 읽기 순서, 32비트 대상 쓰기, 전체 프레임을 독립 계산과 비교했습니다.

교차 영역과 읽기 시작점

  1. 0x528c254c가 부호 있는 사각형 교차 함수 0x530fa324를 호출합니다. 시작 좌표는 더 큰 값, 끝 좌표는 더 작은 값을 택합니다. 두 끝이 닿는 경우에도 교차 상태는 1입니다.
  2. 0x528c2628은 소스 시작 바이트를 (clipY−textY)×76 + clipX−textX로 계산합니다. 이 시험의 추가 X 오프셋은 0입니다. 0x528c262c는 clipY×256 + clipX로 대상 워드 위치를 구합니다.
  3. 0x528c2664가 교차 영역의 첫 대상 워드 하나를 읽습니다. 부분 커버리지의 배경은 이 워드이며, 뒤따르는 각 대상 픽셀의 기존 색을 다시 읽지 않습니다.
  4. 0x528c26b0이 소스를 행 순서로 읽고 0x528c26c8이 비영 커버리지의 워드를 씁니다. 원본 분기에는 255의 단색 경로도 있지만, 시험한 sRGB 마스크에는 255가 없었습니다.

일곱 원점의 읽기와 쓰기

기준 원점은 원본 StringView가 만든 좌표와 뷰 클립을 사용했습니다. 나머지 여섯 경우는 원본 마스크가 생성된 뒤, 0x528c24e4 진입 시 복사된 64바이트 설정의 텍스트 사각형과 viewport만 바꿨습니다. 크기, 팔레트, 소스 X 오프셋, 나머지 설정 바이트와 원래 StringView 객체는 유지했습니다. 대상은 동일한 256×144 합성 RAM 프레임입니다.

경계 접촉 사례의 상태는 1입니다. 높이가 0이어서 마스크 읽기와 대상 쓰기가 없었지만, 원본은 높이를 검사하기 전에 대상 시작 워드 하나를 읽고 캐시를 준비했습니다. 프레임은 그대로였습니다. 이 결과는 시험용 viewport가 표면 안에 있는 조건에 한정됩니다.

독립 스칼라 계산은 원본 마스크의 3040개 셀을 직접 방문하고 각 대상점이 viewport 안인지 검사했습니다. 부분 커버리지의 값은 원본 가중치와 한 배경 워드에서 계산했습니다. 소스 읽기 오프셋의 순서, 대상 주소·워드의 순서, 최종 프레임 147,456바이트가 일곱 경우 모두 일치했습니다. 프레임 앞뒤 64바이트와 기존 할당 보호값도 유지됐습니다. 기준 사례의 전체 실행 해시는 선행 sRGB 재현과 일치했습니다. 기준 전송의 원본과 계산

Q7과 비교할 수 있는 동작

같은 좌상단 입력 (−9,−12)에서 III는 교차 영역의 첫 대상 행에 38워드를 썼습니다. Q7의 별도 실험은 18×48 단일 글리프를 8비트 인덱스로 그립니다. 그 경우 Q7의 행 시작 주소 검사가 대상 행 0의 X=0..7에 해당하는 인덱스 8개를 남겨 두었습니다. III의 76×40 전체 문자열 마스크에서는 해당 여덟 위치의 커버리지가 처음부터 0입니다. 두 사례가 보여주는 차이는 첫 행을 처리하는 순서입니다. 기종 간 텍스트 전송의 기준 · Q7 고정 실행 기록

각 사례의 원본 행·글꼴·팔레트 준비에는 기존 모델 호출 72개가 있습니다. 0x528c2560에서 재개한 최종 전송은 원본 assertion까지 실행했으며 모델 호출은 0개입니다. 실제 UI의 viewport 생산자, 회전 모드, LCD 출력과 화면 이식은 미확인입니다.

원본 재현

Python과 Unicorn 2.1.4에서 고정된 decoded 입력을 사용합니다. 검증기는 보조 소스와 전체 공개 기록의 SHA-256을 확인한 뒤 실행합니다. 기본 동작은 일곱 사례 전체를 비교합니다. --case는 하나만 실행해 해당 사례의 전체 실행 해시와 공통 메타데이터를 고정 기록과 비교합니다. 출력 파일은 새 이름을 사용합니다.

python -B tools/verify_colorspace_clip.py decoded.bin --output clip-all.json
python -B tools/verify_colorspace_clip.py decoded.bin --case upper_left --output clip-corner.json
python -B -m unittest discover -s tests -p test_colorspace_clip.py
