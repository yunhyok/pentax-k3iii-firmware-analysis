K-3 III · 시각 조회의 출력 경계

두 시각 조회 함수의 출력 필드

주 시각과 하위 반환값은 서로 다른 포인터에 저장된다. 보정값을 더하는 경로와 카운터만 읽는 경로를 원본 ARM으로 재현했으며 실제 호출자와 시간 단위는 아직 연결하지 못했다.

하위 산술출력 구조진입 조건검증 범위

상위 word가 앞에 놓이는 구조

두 함수는 진입 인수 r0를 주 시각 출력 포인터, r1을 하위 정수 출력 포인터로 보존한다. 하위 함수 0x525b5c60의 반환값을 r1 쪽에 먼저 저장한 뒤 주 시각의 두 word를 기록한다. 각 word는 32비트다. 명령·해시·표 근거

함수주 시각 계산출력 +0출력 +4기록 순서
0x525ce390NOW64 + OFFSET64
mod 2⁶⁴		상위 32비트하위 32비트하위 정수 → +0 → +4
0x525ce45cNOW64상위 32비트하위 32비트하위 정수 → +4 → +0

NOW64는 0x54c40e50, OFFSET64는 0x54c3fd20에서 읽는다. 여기서 OFFSET64는 이전 예약 계산에 사용된 0x54c40580의 32비트 TTimPeriod와 다른 값이다. 따라서 출력 버퍼를 일반적인 little-endian uint64 메모리로 간주해 읽으면 두 word의 위치를 잘못 해석할 수 있다.

합성 NOW·OFFSET으로 32비트 carry와 64비트 순환을 검증했다. 하위 출력은 기존 산술식과 일치했다. 두 출력 버퍼는 시험에서 겹치지 않으며 동시 접근에 대한 일관성과 포인터 alias의 동작은 검증하지 않았다.

출력 이전에 확인하는 실행 문맥

두 함수는 IRQ helper와 lock helper를 거친 뒤 MPIDR의 하위 2비트로 CPU별 상태를 읽는다. 해당 task 포인터가 없거나 task[0x2b] & 0xf7이 0이 아니면 읽기 경로로 진행한다. 그 외에는 0x54c3f4dc의 CPU별 값을 부호 있는 수로 비교해 양수일 때만 진행한다.

마지막 값이 0 이하인 선택 경로는 출력 전에 0x525d724c로 이동한다. 시험은 이 주소에서 멈췄다. 이 함수가 실제로 반환하는지, 중단하는지와 lock·IRQ 상태를 어떻게 처리하는지는 이번 결과로 판단하지 않는다. 디컴파일 C는 이 조건 분기를 누락하므로 원본 ARM을 기준으로 분석했다.

디스패치 표의 0x525d7b64, 0x525d7b68은 각각 두 함수 주소를 담고 있다. 확인된 표 기준 주소 0x525f7660에 대한 signed index는 −32447·−32446이다. 상위 16비트 값 0x8141·0x8142에 대응하지만 완전한 요청 번호를 만드는 wrapper나 실제 요청 생산자는 확인하지 못했다. 표에 주소가 있다는 사실만으로 런타임 사용을 확정하지 않는다.

함수별 6사례, 총 12사례

각 함수에서 0·carry·순환·task flag 허용·상태값 허용·오류 경계의 6사례를 검사했다. RTOS·decoded 입력의 결과가 동일했다. Unicorn에서 읽은 MPIDR가 CPU 0을 선택하도록 동작한 조건이며 다른 CPU 번호는 시험하지 않았다. 12사례 결과

원본 하위 변환 함수도 함께 실행했다. IRQ mask·restore와 lock·unlock은 대체 함수다. 중첩된 두 IRQ token의 복원 순서, lock 인수, 출력 기록 순서와 주변 sentinel 보존을 검사했으며 실제 IRQ·lock의 효력은 재현하지 않았다.

추가 genuine C는 2개다. 이 보고서의 ARM 113 words는 앞선 하위 산술 보고서에서 정적으로 보존한 범위와 겹친다. 새로운 검증은 두 조회 함수의 선택 경로 실행이며 신규 원본 명령 113개를 더 발견했다는 뜻은 아니다.

재현 명령
python verify_update_clock_readers.py rtos.bin --output clock-readers.json

재현 도구는 decoded 입력도 지원한다. 원본 C·ASM·바이너리는 로컬에 보존한다. 카메라 I/O·펌웨어 빌드·플래시는 수행하지 않았다.

실제 상위 소비자, 시간 단위, 도달 가능한 카운터 범위와 촬영 동작에 미치는 영향은 미확정이다. 이번 출력 구조만으로 실제 timestamp의 역행이나 카메라 결함을 판단하지 않는다.

정적 근거와 합성 CPU 실행의 결과다. 실제 하드웨어는 미검증이며 보고서는 320·390·1280px에서 렌더링했다.
