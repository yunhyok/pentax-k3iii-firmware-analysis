Lightroom TIFF의 프로파일 지문 재현

시험 DCP 여섯 개에서 Adobe DNG SDK의 전체 프로파일 지문을 계산했다. 여섯 값 모두 Lightroom이 내보낸 TIFF의 XMP CameraProfileDigest와 일치했다. 계산에는 정규화한 색 행렬과 광원, 프로파일 이름, 정책 값, 곡선이 있을 때의 FLOAT 쌍이 들어갔다.

DCP 태그에서 TIFF 지문까지

SDK는 각 행렬의 D50 PCS 응답 중 최댓값이 양수이면서 0.99–1.01 범위를 벗어나면 행렬을 그 값으로 나눈다. 원소에는 binary64로 10,000을 곱한 뒤 SDK의 부호 있는 정수 반올림을 적용한다(dng_utils.h 651–663행). 계산 순서는 광원 1(2바이트), 행렬 1(72바이트), 광원 2(2바이트), 행렬 2(72바이트), 이름(NUL 제외), 기본 embed policy(4바이트 값 0), 선택적 톤 곡선 순이다. 행렬 하나에는 SRATIONAL 9개, 곡선에는 FLOAT 좌표 쌍이 들어간다. SDK 소스의 dng_camera_profile.cpp 265–315, 510–520, 562–827행과 dng_image_writer.cpp 482–501행에 해당한다. SDK의 빌드 번호 2768은 dng_flags.h 30행, 곡선 점 한도 8,192는 dng_sdk_limits.h 72행에서 확인했다. 같은 지문으로 남는 변화

이 태그 조합에서 전체 프로파일 지문(Fingerprint)에는 이름과 embed policy가 들어가고 렌더 데이터 지문(RenderDataFingerprint)에는 빠진다. 모델 제한 문자열은 두 지문에 포함되지 않는다. SDK의 별도 UniqueID는 전체 지문의 16바이트에 모델 제한 문자열을 붙여 MD5를 계산한다. 근거는 dng_camera_profile.h 691–714·966–974행과 dng_camera_profile.cpp 831–855행이다. 소스 위치와 합성 대조

  • 합성 DCP의 이름만 바꾸면 전체 지문만 달라졌다. 모델 제한을 바꾸면 두 지문이 모두 같았다.
  • embed policy가 명시된 DCP는 이 검사기의 지원 범위 밖이다. 정책 값 합성 대조는 DCP 태그 대신 MD5 입력 스트림의 정책 값만 바꿨다.
  • 넷째 자리 반올림에서 사라지는 작은 계수 변화와 정규화에서 상쇄되는 균일 스케일은 지문을 바꾸지 않았다. 유효 자릿수가 달라진 행렬, 광원, 곡선 수정은 두 지문에 반영됐다.
  • 합성 DCP 파일을 big-endian으로 다시 담아도 읽은 값이 같으면 지문은 같았다. 지문 입력을 big-endian으로 직렬화했을 때는 달라졌다.

확인한 SDK에서 0인 행렬 원소의 SRATIONAL은 0/1이다. 실제 DCP 여섯 개에는 정규화 뒤 0인 행렬 원소가 없어서 이 출력들만으로 Lightroom의 0 직렬화 규칙은 판별할 수 없다. 동일 지문이라도 DCP 파일 바이트나 모델 제한은 다를 수 있다. 이 대조는 프로파일 지문 재현에 한정되며 파일 인증이나 색 정확도는 다루지 않는다. 행렬의 0 개수와 합성 대조 결과

같은 파일로 재현

Python 3.11 이상과 tifffile을 사용한다. --sdk에는 Adobe ZIP, --dcps에는 DCP 여섯 개가 있는 폴더, --exports에는 TIFF 하위 폴더를 모아 둔 경로를 준다. 파일 배치는 JSON의 input_layout에 있다. 검사는 정확히 일치하는 파일 해시를 요구하며 결과는 새 경로에만 쓴다. SDK 소스, 원본 DCP·TIFF, 제조사 행렬과 곡선 값은 공개 파일에 포함하지 않았다. 입력 배치와 해시 · 검사 코드

$f = 'fingerprint-fixtures'
python -B tools/check_lightroom_profile_fingerprints.py `
  --sdk "$f/dng-sdk.zip" --dcps "$f/dcps" --exports "$f/exports" `
  --output "$f/fingerprint-replay.json"
Get-FileHash -Algorithm SHA256 -LiteralPath "$f/fingerprint-replay.json", analysis/lightroom-profile-fingerprints.json
