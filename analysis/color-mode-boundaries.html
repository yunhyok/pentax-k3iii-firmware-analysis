재현

Python 3.11 이상과 Unicorn 2.1.4를 사용한다. 입력은 K-3 Mark III 2.20 전체 해제 BIN이며 도구는 파일 크기와 SHA-256을 확인한다. 공개 기준 JSON 네 개는 LF로 정규화한 SHA-256을 확인한다. 결과 경로는 새 파일이어야 한다. 재현 도구

python -B tools/check_color_mode_boundaries.py decoded.bin --output color-mode-boundaries-replay.json
