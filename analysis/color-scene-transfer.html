Lightroom 색 프로파일 · K-3 II #1363

차트의 톤 곡선을 다른 장면에 적용한 결과

차트 #1376의 무채색으로 구한 곡선을 고정하고, 다른 K-3 II로 찍은 야외 RAW #1363에서 카메라 Natural 내장 JPEG와의 색차를 쟀습니다.

이 문서에서

  1. 고정 곡선을 적용하자 24개 영역의 색차가 줄었습니다
  2. 곡선과 비교 영역을 미리 고정했습니다
  3. 같은 차트의 Lightroom 15.6·16.0 출력을 먼저 비교했습니다
  4. 이 결과의 범위는 야외 장면 한 장입니다
  5. 재현 방법
  6. 근거 파일

고정 곡선을 적용하자 24개 영역의 색차가 줄었습니다

영역별 중앙 ΔE00의 평균이 행렬 TIFF의 5.374에서 4.067로 줄었습니다. 같은 지표에서 Camera Natural은 3.948, Adobe Standard는 5.026이었습니다.

같은 픽셀을 비교한 세 범위
범위표본 픽셀행렬행렬 + 고정 톤Camera NaturalAdobe Standard
24개 영역 전체221,1845.3744.0673.9485.026
낮은 기울기, 채널 끝값 제외53,4634.8053.3493.0584.533
위 조건과 내부 매듭 범위51,1644.7863.2933.0534.536

세 범위 모두 24개 영역의 중앙 ΔE00가 개선됐습니다. 전체 범위에서 영역별 평균 절대 ΔL*를 같은 방식으로 집계하면 4.084에서 2.440으로 줄었습니다. Camera Natural은 표의 세 범위에서 영역별 중앙값 평균이 가장 낮았습니다. 전체 픽셀을 합쳐 계산한 p90은 고정 톤 8.079, Camera Natural 8.139로 순서가 달랐습니다. 영역별 수치와 분포 요약

곡선과 비교 영역을 미리 고정했습니다

  1. #1376 차트에서 톤 결정무채색 여섯 패치의 휘도 관계와 (0, 0), (1, 1)을 고정한 단조 3차 곡선(PCHIP)을 가져왔습니다.
  2. #1363의 원래 크기 출력 세 개 확보같은 RAW를 행렬 DCP, Camera Natural, Adobe Standard로 현상했습니다. 카메라 기준은 같은 RAW 안의 Natural JPEG입니다.
  3. 위치 등록 뒤 같은 영역 비교JPEG와 행렬 TIFF를 맞춘 후 24개 96×96 영역에서 세 현상 결과와 행렬 TIFF에 고정 톤을 더한 값을 비교했습니다.

공간 위치는 색차와 별개로 결정했습니다. 초록 채널을 흐리게 한 뒤 Sobel 기울기 크기 패턴으로 고정 위치 20곳을 대조했습니다. 교대로 나눈 10곳으로 affine 좌표 변환을 구했고, 남은 10곳의 최대 잔차는 0.0571px였습니다. 세 TIFF의 공통 좌표를 쓰기 전에 행렬 TIFF 기준 최대 이동이 Camera Natural 0.0206px, Adobe Standard 0.0612px임을 확인했습니다. 두 번째 집계는 기울기가 낮고 어느 입력에도 채널 끝값이 없는 픽셀을 사용했습니다. 세 번째는 여기에 세 선형 행렬 RGB 채널이 차트의 내부 매듭 범위에 드는 조건을 더했습니다. 고정 좌표·마스크·통과 기준

TIFF의 내장 ProPhoto ICC와 JPEG의 sRGB를 LittleCMS 상대 색도 변환에 사용해 D50 Lab으로 바꿨습니다. 고정 톤은 선형 ProPhoto RGB의 최솟값과 최댓값에 곡선을 적용하고 중간 채널은 원래 상대 위치로 보간했습니다. 이 식은 Adobe DNG SDK 1.7.1의 RefBaselineRGBTone을 참고했습니다. 여기서는 이미 현상된 TIFF에 적용하는 오프라인 계산이며 Lightroom의 내부 연산이나 DCP 설치를 재현하는 단계는 없습니다. 차트의 톤 계산 · Adobe DNG SDK 배포처

같은 차트의 Lightroom 15.6·16.0 출력을 먼저 비교했습니다

#1376에 같은 행렬 DCP를 적용한 두 TIFF에서 디코딩한 RGB16 픽셀 24,064,000개와 내장 ICC가 바이트 단위로 일치했습니다. 현상 XMP에서는 Version이 18.7에서 19.0으로 바뀌었고 ReshapeAmount=0이 추가됐습니다. ProcessVersion 15.4와 나머지 기록된 현상값은 같았습니다. 이 대조는 #1376의 행렬 프로파일과 해당 설정 한 건에 해당합니다. 버전 대조 결과

두 RAW는 기종과 펌웨어 버전 1.10이 같고 바디 식별자가 달랐습니다. 내장 ColorMatrix 두 개와 AsShotNeutral도 달랐습니다. 실험에는 #1376 시험 DCP를 그대로 적용했습니다. As Shot을 유지했을 때 #1363의 Lightroom 표기는 행렬이 4650 K/+28, Camera Natural과 Adobe Standard가 4800 K/+30이었습니다. 셋 다 Exposure 0.00이며, 이 비교가 같은 센서 화이트밸런스 배율을 보장하지는 않습니다.

이 결과의 범위는 야외 장면 한 장입니다

카메라 Natural JPEG는 이 실험의 출력 기준입니다. 장면의 절대 색 참값은 측정하지 않았습니다. 바디, 렌즈, 촬영 조건, 화이트밸런스와 카메라의 그림자 보정이 차트와 달랐습니다. 남은 색차를 어느 단계가 만들었는지 분리하거나, 같은 곡선이 다른 장면과 조명에서도 개선된다고 판단할 수 없습니다. 24개 영역과 그 안의 픽셀은 한 RAW에서 얻은 관찰값입니다.

재현 방법

두 RAW는 raw.pixls.us의 CC0 1.0 표본입니다. #1363은 pentax-k3ii-1363.dng, #1376은 pentax-k3ii-1376.dng로 두고, #1363의 SubIFD1:PreviewImage에서 6016×4000 JPEG를 추출합니다. MakerNote에는 다른 작은 프리뷰도 들어 있습니다. Python의 subprocess로 stdout 바이트를 직접 저장하면 셸의 텍스트 변환을 피할 수 있습니다. #1363 DNG · #1376 DNG · CC0 1.0

python -c "from pathlib import Path; import subprocess; Path('pentax-k3ii-1363-preview.jpg').open('xb').write(subprocess.check_output(['exiftool','-b','-SubIFD1:PreviewImage','pentax-k3ii-1363.dng']))"
python -B tools/profile_bridge.py analysis/lightroom-matrix-1376.json matrix1376.dcp

시험 DCP의 SHA-256은 6aa402a77f6b41f9fa37e99f1bd6911447e74c112eb7f7601c8c3bb116570ee4입니다. #1376의 ColorMatrix와 보정 조명만 사용하는 고정 레시피입니다. Lightroom에서 이 DCP를 선택하고 #1376 TIFF를 버전 15.6과 16.0에서 각각 준비합니다. #1363은 버전 16.0에서 세 프로파일을 번갈아 적용합니다. DCP 레시피

공통 현상 설정은 ProcessVersion 15.4, SDR, As Shot, 노출 0.00, 기본 톤·채도, 자르기 없음, 렌즈 프로파일·CA·기하 보정 끔입니다. 캡처 샤프닝은 40, 반경 1.0, 세부 25, 마스킹 0이며 휘도 NR 0, 색상 NR 25입니다. TIFF는 무압축 unsigned RGB16 ProPhoto, 원래 크기, 출력 샤프닝·워터마크·재가져오기 끔으로 내보냅니다. 현상 XMP가 포함되도록 메타데이터를 보존합니다. #1363 TIFF의 파일명은 각 폴더에서 pentax-k3ii-1363.tif입니다. 하위 폴더 이름은 matrix1376, camera-natural, adobe-standard입니다. Adobe 내보내기 설정

Python 3.11 이상, NumPy, SciPy, OpenCV, Pillow, scikit-image, tifffile, ExifTool과 LittleCMS tificc가 필요합니다. work는 만들어 둔 작업 폴더이고 결과 경로는 새 파일이어야 합니다. 아래 명령은 기록한 TIFF 파일 전체의 해시를 요구합니다.

python -B tools/check_color_engine_bridge.py --raw pentax-k3ii-1376.dng --old-tiff chart-15.6.tif --new-tiff chart-16.0.tif --output bridge.json
python -B tools/check_color_scene_transfer.py --raw pentax-k3ii-1363.dng --preview pentax-k3ii-1363-preview.jpg --exports exports --bridge chart-16.0.tif --exiftool exiftool --tificc tificc --scratch work --output transfer.json

새로 내보낸 TIFF는 저장 시각과 XMP 식별자에 따라 전체 파일 해시가 달라질 수 있습니다. 이 경우 --allow-fresh-export를 지정합니다. 버전 대조의 두 차트 출력과 장면 검증에 쓰는 16.0 차트 출력은 기록된 RGB·ICC·현상 설정이 같아야 합니다. #1363 TIFF는 기록된 프로파일과 현상 설정·ICC를 확인한 뒤 RGB와 색차를 새로 측정합니다. RAW·JPEG·곡선·등록 기준은 고정합니다. 색차를 계산하기 전에 등록만 확인하려면 --registration-only를 사용합니다.
