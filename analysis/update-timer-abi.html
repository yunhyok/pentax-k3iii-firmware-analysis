0x525d088c부터의 선택 경로는 두 번의 ADD·ADC로 세 값을 더한다. 결과는 64비트 범위를 넘으면 순환한다. 원본 메타데이터 기록 함수 0x525b805c는 예약값과 callback 0x525cdfa0, alarm 객체 포인터를 저장한다. 이어지는 큐 삽입 0x525b7e00은 stub으로 대체했다. 별도 값의 생산자와 실제 시간 단위는 미확정이다.

상태 조회의 선택 경로 0x525d0bfc는 flags의 bit 0이 설정되어 있을 때만 예약값−현재값−별도 값을 계산한다. 64비트 결과를 부호 있는 수로 보아 음수이면 0으로 만들고 그 외에는 하위 32비트를 남은 시간 필드에 쓴다. bit 0이 꺼져 있으면 남은 시간은 0이다. 구조체+8에는 flags & ~6을 쓰므로 단순히 bit 0만 추출하는 연산은 아니다.

32비트 carry·64비트 순환·음수 clamp·큰 양수의 하위 32비트·추가 flags 비트를 합성 입력으로 검사했다. 이 경계값이 실제 커널 상태에서 발생한다는 증거는 아니다. 상위 wrapper가 구조체+8을 정확히 1과 비교한다는 결과는 서비스 분석에 기록했다.

17사례의 범위

디스패치 일부 3사례·예약 산술 5사례·상태 산술 9사례가 RTOS·decoded 입력에서 동일하게 통과했다. 각 실행은 지정한 명령 범위에 제한했다. 실제 SVC 예외·IRQ·scheduler·clock은 실행하지 않았으며 전체 함수의 전제 조건도 재현하지 않았다. 17사례 결과

genuine C 2개, 지원 범위 7개와 ARM 453 words를 로컬에 보존했다. 상태 조회 C에는 잘못 복원된 자기 반복 goto가 있어 원본 ARM과 실행 결과로 판정했다. 카메라·OS·저장소 I/O와 빌드·플래시는 수행하지 않았다.
