K‑3 III와 Q7의 시험 DCP로 TIFF 내보내기

두 카메라의 DNG에서 읽은 색 행렬과 광원 태그로 만든 시험 DCP를 Lightroom에서 선택했다. K‑3 III는 6192×4128, Q7은 4000×2664의 비압축 ProPhoto RGB 16비트 TIFF로 내보냈다. TIFF의 XMP에서 선택한 프로파일을 확인하고 전체 픽셀을 디코딩했다.

Lightroom의 두 TIFF에는 같은 ProPhoto RGB ICC가 들어 있다. 두 파일 모두 3채널 unsigned 16비트 RGB이며, 비압축 상태로 크기 조정·출력 샤프닝·워터마크를 끄고 내보냈다. XMP에서 노출 0 EV, Process Version 15.4와 HDR 편집 꺼짐을 확인했다. 파일의 SHA-256은 TIFF 전체를, 픽셀 SHA-256은 디코딩 후 행 순서대로 직렬화한 little-endian RGB16 값을 대상으로 계산했다. TIFF·ICC·픽셀 해시와 설정값

두 RAW의 작업용 사본과 두 DCP의 설치본은 각각 원본과 일치했다. Q7의 일반 Model 태그는 PENTAX Q7이고, DNG와 DCP의 UniqueCameraModel에는 Q7 뒤에 ASCII 공백(0x20)이 하나 있다. 두 파일의 모델 태그는 마지막 NUL까지 일치했다. XMP의 CameraProfileDigest는 Lightroom이 기록한 별도 식별값이다. RAW 출처와 원래 DCP 검사 · DCP 태그와 역할

RAW 기본 크롭과 XMP에 기록된 크롭

두 RAW의 방향 태그는 1, DefaultScale은 1×1이다. 내보낼 때 크기를 조정하지 않았으므로 TIFF의 예상 크기는 CFA 배열 전체가 아니라 RAW의 DefaultCropSize에서 계산했다. K‑3 III의 XMP는 HasCrop=False로 좌표가 전체 범위 [0, 0, 1, 1]이다.

Q7의 XMP는 HasCrop=True다. 좌·상·우·하 경계가 [0, 0.056, 1, 0.944]이며 각도는 0이다. 4000×3000 활성 영역에서 위아래 168행씩 제외한 RAW 기본 크롭과 정확히 일치한다. Adobe DNG 규격의 기본 크롭

내장 JPEG는 DNG에서 따로 추출해 확인했다. K‑3 III는 Natural과 Adobe RGB로 기록됐고 Q7은 Bright이며, 내장 미리보기의 DNG 기본 sRGB는 MakerNote와 일치한다. 두 JPEG에 ICC는 없었다. TIFF와 각각 크기가 같지만, 이 검증에서는 카메라 JPEG와의 색 차이나 보정 정확도를 측정하지 않았다. K‑3 II의 별도 실험은 여섯 TIFF와 Natural 미리보기를 패치 단위로 비교했다. DNG 미리보기 색공간 · K‑3 II 여섯 TIFF 비교

원본 산출물 검증 재현

두 RAW는 CC0 표본이다. 정확한 수치 재현에는 JSON에 적힌 SHA-256과 일치하는 RAW, DCP, TIFF가 각각 필요하다. 이 페이지에는 DCP·TIFF·ICC 원본 바이트가 포함되어 있지 않다. 새로 내보낸 TIFF는 픽셀이 같아도 파일 메타데이터가 달라 해시가 달라질 수 있다. raw.pixls.us 원본 저장소 · CC0 1.0 · 원본 URL 및 파일 해시

저장소 루트에서 Python 3.11 이상과 NumPy, Pillow, tifffile을 사용한다. ExifTool 실행 파일은 --exiftool로 지정하거나 PATH에 둔다. 아래 예시의 파일 경로는 각자 보관한 파일 위치로 바꾼다. 출력 JSON은 새 파일이어야 한다. 재현 스크립트

$f = 'model-fixtures'
python -B tools/check_lightroom_model_exports.py `
  --k3iii "$f/pentax-k3iii-4678.dng" "$f/pentax-k3iii-4678-matrix-test.dcp" "$f/pentax-k3iii-4678.tif" `
  --q7 "$f/pentax-q7-1760.dng" "$f/pentax-q7-1760-matrix-test.dcp" "$f/pentax-q7-1760.tif" `
  --exiftool exiftool --output "$f/model-export-replay.json"
Get-FileHash -Algorithm SHA256 -LiteralPath "$f/model-export-replay.json", analysis/lightroom-model-exports.json
