Lightroom 색 프로파일 · K-3 III

원본 PEF와 변환 DNG의 CFA 샘플 비교

K-3 III PEF와 Adobe DNG Converter 18.7이 변환한 DNG에서 디모자이크 전 CFA 샘플 26,628,096개가 모두 같았습니다. 변환 DNG의 WhiteLevel은 원본 MakerNote에 기록된 값과 달랐습니다.

이 문서에서

  1. 세 배열의 모든 위치를 비교했습니다
  2. 같은 CFA 배열에 기록된 WhiteLevel은 달랐습니다
  3. 고정 PEF·DNG를 다시 비교하는 방법

세 배열의 모든 위치를 비교했습니다

rawpy는 LibRaw의 unpack 뒤 원본 크기의 raw_image 배열을 노출합니다. 스크립트는 디코더가 열린 동안 이 배열을 복사합니다. 비교에는 디모자이크, 화이트밸런스 적용, 크롭, 노출 보정, 블랙 레벨 차감이 들어가지 않았습니다. 별도 검토에서 디코더의 버퍼 열기와 unpack을 명시적으로 호출해 배열의 동등성을 직접 확인했습니다. rawpy 게시 커밋의 원본 배열 구현 · LibRaw Pentax 디코더

세 배열을 리틀엔디언 uint16 행 우선 순서로 직렬화한 SHA-256은 모두 b5dbb0a1bcaf6d4002a54c0069fbfd52e17964156cdf7359ae10395519b145b3입니다. RGGB의 네 위치에서도 각각 6,657,024개가 일치했습니다. 전체 비교 결과와 독립 검토 데이터

같은 CFA 배열에 기록된 WhiteLevel은 달랐습니다

확인 위치WhiteLevel 또는 maximum
PEF Pentax MakerNote WhiteLevel16,378

저장 CFA의 최댓값은 16,382였고 DNG WhiteLevel 16,315를 넘는 샘플은 8,565개였습니다. 그 값도 잘라내지 않고 대조했습니다. 두 rawpy 입력의 채널별 블랙 레벨은 모두 64였습니다. rawpy의 채널 표는 RGBG 인덱스 [[0,1],[3,2]], DNG의 CFA 태그는 RGB 인덱스 [[0,1],[1,2]]이며, 두 표는 동일한 RGGB 위치를 가리킵니다. 태그·채널·유효 영역 기록 · rawpy 메타데이터 속성

이 결과는 보존한 PEF 한 개와 해당 첫 DNG 변환의 디코딩 배열에 한정됩니다. WhiteLevel과 중립값 등 현상에 쓰이는 메타데이터는 배열과 별도로 해석됩니다. Lightroom에서 PEF와 DNG가 같은 렌더를 만드는지는 검사하지 않았습니다. 변환 조건과 AsShotNeutral 검증

고정 PEF·DNG를 다시 비교하는 방법

원본 PEF와 첫 변환 DNG의 크기 및 SHA-256을 확인합니다. 새 변환은 날짜나 UUID 때문에 파일 해시가 달라질 수 있습니다. 검증기는 고정 파일 쌍과 원래 결과 전체의 SHA-256을 대조한 후에만 새 JSON을 씁니다. 두 원본 파일과 디코더 바이너리는 이 자료에 포함하지 않았습니다. 입력 핀 · Converter 실행 기록

CPython 3.12.3 Windows x86-64, NumPy 1.26.4, tifffile 2023.4.12, imagecodecs 2023.1.23을 사용했습니다. rawpy는 0.28.0, 관측한 LibRaw 버전은 0.22.2입니다. 같은 환경에서 rawpy가 필요하면 공식 wheel을 내려받고 JSON의 SHA-256과 비교한 후 전용 디렉터리에 설치합니다. 스크립트는 설치를 수행하지 않습니다. 공식 wheel과 선택한 설치 파일들의 바이트를 대조했으며, 이 해시로 전체 런타임의 DLL과 의존성을 인증한 것은 아닙니다. 공식 rawpy wheel과 SHA-256

Get-FileHash ./rawpy-0.28.0-cp312-cp312-win_amd64.whl
python -m pip install --no-deps --target .cfa-deps ./rawpy-0.28.0-cp312-cp312-win_amd64.whl
$env:PYTHONPATH = (Resolve-Path .cfa-deps).Path
python -B tools/check_lightroom_cfa_preservation.py --pef K3IIIhSLI0000100NR0.PEF --dng first-converted.dng --output cfa-replay.json

위 환경 변수는 이 PowerShell 세션에 적용됩니다. 설치가 이미 끝난 전용 환경이라면 마지막 명령만 사용합니다. 재현 코드

후속 CFA 범위와 기본 크롭 분석은 WhiteLevel 초과 샘플이 유효 영역과 크롭에 남는 위치를 대조하고, 공개 SDK의 기본 정규화 수식을 별도로 계산합니다.
