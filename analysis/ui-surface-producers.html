K-3 III StringView의 그리기 표면

등록 Canvas의 표면 포인터는 스냅샷을 거쳐 중첩 객체의 그리기 호출로 전달됩니다. 그리기 대상이 StringView의 내부 객체일 때, 원본 표의 +0x14 슬롯이 0x52bedb40을 선택합니다.

이 문서에서

  1. 표면 포인터의 전달
  2. 입력 버퍼 기술자에서 복사하는 필드
  3. 정적 검증 재현

표면 포인터의 전달

0x526d9454는 +0x30이 활성인 0x34바이트 슬롯에서 표면을 조회하고, 0x526d951c–0x526d9524가 슬롯의 Canvas 포인터와 슬롯+8을 0x52bea3f0에 전달합니다. 등록 갱신 함수는 0x526d9560의 검사 결과가 0이면 복귀합니다. 조건을 통과하면 갱신한 뒤 같은 활성 슬롯의 Canvas에 뷰 스냅샷을 호출합니다. Canvas 표 0x5386f680의 +0x60은 0x52bea084이며 +0x1e0을 +0x1d8로 복사합니다. 별도 그리기 함수 0x52bea3f8은 +0x1d8을 읽고, 표면의 u16 +0x1c가 0이면 돌아갑니다. 원본 구간·함수 표의 해시

선택된 Canvas 분기는 내부 객체 +0x178과 같은 표면을 순회 함수에 전달합니다. 뷰 스냅샷의 0x52c02608은 하위 뷰 +0x114의 내부 객체 포인터를 가져옵니다. 0x52c02718의 가상 호출은 내부 표 +0x14를 읽고 들어온 표면 포인터 r1을 유지합니다. 하위 호출은 저장한 포인터를 다시 r1에 넣습니다.

생성자 연결은 자동 대조 38개와 별도로 고정 RTOS에서 확인했습니다. StringView를 V라 하면 0x52bee2f0이 리터럴 0x52bee414에서 표 주소 0x5386fec0을 읽고, 0x52bee2fc가 내부 객체 V+0x11c에 씁니다. 0x52bee3fc → 0x52c0025c는 그 내부 객체의 주소를 V+0x114에 저장합니다. 순회 대상이 이 객체이면 표 슬롯이 0x52bedb40을 선택합니다. 여기서 N+0x64가 0이 아닐 때 0x52bedb78이 표면을 N+0x6c의 config 첫 워드에 씁니다. 실제 메뉴에서 특정 StringView가 이 목록에 연결되는지는 미확인입니다. viewport와 텍스트 설정의 전달

입력 버퍼 기술자에서 복사하는 필드

슬롯에서 호출하는 0x528f66a4 → 0x5310e4ec는 먼저 표면 헤더를 초기화합니다. 조회 모드 1·2에서 필요한 객체와 레코드가 있으면 0x53114538이 화면 입력 버퍼 기술자 D의 필드를 표면 S에 복사합니다. 조회가 성립하지 않으면 초기화 상태가 남을 수 있습니다. 원본 진단의 파일명은 ScreenBuffer/ScreenInputBuffer.cpp입니다. 진단 문자열 및 필드 저장 근거

GetWidth와 GetHeight 진단 이름은 자동 검사에 포함된 문자열 6개와 별도로 원본 0x53a73e18과 0x53a73dcc에서 확인했습니다.

형식 5는 그리기 디스패처가 0x528c2e74에서 검사하는 조건입니다. 타입 5 비회전 전송에서 전역 너비는 32비트 워드 단위의 행 간격으로 쓰입니다. 0x528c265c에서 워드 위치를 4배 해 바이트 주소로 바꾸고, 0x528c26c8에서 한 워드를 씁니다. 이 경로를 사용하는 실제 메뉴 객체, 버퍼 할당 주소와 치수, LCD 출력은 확인되지 않았습니다. 이전 시험의 256×144는 호스트가 공급한 값입니다. 기존 합성 RAM 표면의 경계 시험

정적 검증 재현

재현 출력은 실행 중 다른 프로세스가 경로를 변경하지 않는 디렉터리에 둡니다.

고정 RTOS 파일을 Python과 Capstone 5.0.7에서 읽습니다. 원본 31구간, A32 명령 38개, 표 값 7개, 진단 문자열 6개를 재구성합니다. 원래 검증 기록 전체의 SHA-256이 일치하면 명령 텍스트를 해시로 바꾸고, 공개 JSON 전체 해시까지 맞을 때 새 파일을 씁니다. CPU나 MMIO는 실행하지 않습니다. 원본과 공개 기록의 해시

python -B tools/verify_ui_surface_producers.py rtos.bin --output surface-replay.json
python -B -m unittest discover -s tests -p test_ui_surface_producers.py
