Lightroom TIFF에서 본 LookTable 효과

K-3 II RAW 한 장에 두 시험 DCP를 적용했다. 항등 LookTable과 비교하면 채도 배율 0.8을 적용한 TIFF는 24개 패치의 평균 ΔE00이 4.645이었다. 항등 표와 LookTable을 생략한 기준 출력은 24개 패치의 Lab 중앙값이 모두 같았다.

같은 색 행렬에 두 LookTable을 넣었다

펌웨어 1.10에서 촬영한 K-3 II DNG #1376의 행렬 두 개와 광원을 썼다. 두 시험 DCP에는 기준 DCP와 같은 모델 제한과 보정 태그를 넣었다. 항등 표의 채도 배율은 1.0, 채도 대조 표는 0.8이다. 두 표 모두 색상 이동은 0°, 명도 배율은 1.0이다. CC0 기준 레시피

ProfileLookTableDims는 LONG 3개다. ProfileLookTableData의 FLOAT 6개는 V, H, S 순으로 중첩해 저장하며 각 엔트리는 색상 이동과 채도·명도 배율을 담는다. 채도 입력이 0인 엔트리도 명도 배율은 1이다. V=1에서는 별도 인코딩 태그가 적용되지 않는다. Adobe DNG 1.7.1.0 사양 56–57·63쪽

처음 가져왔을 때 두 DCP는 목록에서 보이지 않았다. Lightroom을 정상 종료하고 다시 열자 같은 파일이 목록에 나타났다. 두 프로파일을 #1376에 적용하고 실제 TIFF를 내보냈다. 파일의 이름이나 바이트는 바꾸지 않았다.

전체 RGB16 픽셀을 대조했다

모든 TIFF의 크기와 ICC 프로파일이 같았다. Lightroom 현상 속성은 As Shot 5200 K, Tint +2, 노출 보정 0.00 EV와 Process Version 15.4를 포함한다. 114개 속성 중 시험 DCP를 바꿨을 때는 CameraProfile과 CameraProfileDigest만 달랐다. 중첩 요소 6개는 그대로였다.

기존 기준과 이번 기준의 픽셀은 같았다. 항등 표의 재출력도 첫 항등 출력과 일치했다. 이번 세션에서 기준을 항등 표로 바꾸자 34,099픽셀의 코드가 달라졌다. 같은 프로파일의 반복 결과는 이번 촬영과 현상 조건에서 재현됐다. Lightroom 내부에서 이 차이가 생긴 경로는 확인이 남아 있다.

두 시험 DCP의 전체 지문을 SDK 직렬화 순서로 계산했다. 항등 표는 380E26299D96CE6BC04D061D711C8FFA, 채도 0.8 표는 D806FCB7CD7B2132B74AF1C13ED7E430이며 각각 해당 TIFF의 XMP 지문과 일치한다. Adobe DNG SDK 지문 계산 근거

채도 0.8의 24개 패치 색차

기존 #1376 색 비교의 패치 좌표를 사용했다. 19곳을 대조한 결과 최대 이동량은 0.097픽셀이었다. 각 패치의 RGB16을 내장 ICC로 Lab D50으로 변환한 뒤 L*, a*, b*의 중앙값으로 ΔE00을 계산했다. 항등 표 대비 채도 0.8 표에서 최대 ΔE00은 10.031로 8번 패치에 나타났고, 무채색 패치 19–24의 최댓값은 0.850였다. 등록과 ROI 근거

각 패치의 Lab 중앙값에서 구한 C*ab는 24개 모두 감소했다. 감소 폭은 패치마다 달랐다. 0.8은 LookTable 내부 HSV의 채도 배율이다. 카메라 JPEG의 색 정확도와 다른 촬영에서의 재현성은 별도 검증이 필요하다.

해시가 고정된 입력으로 재현

Python 3.11 이상, NumPy, OpenCV, Pillow, scikit-image, tifffile과 Little CMS의 tificc가 필요하다. 경로 예시는 보유한 RAW·TIFF·DCP와 기존 임시 디렉터리로 바꾼다. --compare는 저장소 JSON과 측정값이 일치하는지도 검사한다. 결과는 새 경로에만 쓴다. 입력 해시와 측정값 · 재현 코드

python -B tools/check_lightroom_look_controls.py --raw sample.dng   --omitted-tiff baseline-prior.tif --omitted-current-tiff baseline-current.tif   --identity-dcp look-identity.dcp --identity-tiff identity.tif   --identity-repeat-tiff identity-repeat.tif   --sat80-dcp look-sat80.dcp --sat80-tiff sat80.tif   --scratch scratch --output replay.json --compare analysis/lightroom-look-controls.json

DCP를 재생성하려면 CC0 기준 레시피의 ProfileName을 검증 JSON의 해당 name으로 바꾼다. ProfileLookTableDims에 [1,2,1]을, ProfileLookTableData에 [[0,s,1],[0,s,1]]을 넣는다. s는 1.0 또는 0.8이다. 이 레시피를 profile_bridge.py에 넘기면 두 파일을 다시 만들 수 있다.
