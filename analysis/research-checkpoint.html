공개 전 연구 여덟 건의 요약과 다음 확인 지점

세 기종에서 로컬 검토까지 마친 연구 여덟 건을 짧게 정리했습니다. 원본 검사기와 실행 기록은 아직 공개하지 않았으므로, 이 문서는 무엇을 했는지 알리는 요약이지 재현 자료가 아닙니다.

이 문서에서

  1. 검증과 공개의 단계
  2. 로컬 검토를 마친 결과 여덟 건
  3. 다음 확인 지점
  4. 근거 파일과 참고 자료

핵심 요약

  • K-3 III 3건, Q7 4건, K-3 II 1건의 연구가 로컬 검토까지 끝났습니다. 검토는 결과를 다른 방법으로 다시 실행하거나 계산해 대조하는 단계입니다.
  • 각 연구의 전체 근거(원본 검사기, SDK 실행, 실행 기록)는 아직 공개하지 않았습니다. 이 문서와 요약 JSON에 적은 해시는 로컬에 보관한 근거 파일을 가리키는 식별값입니다.
  • 여기 적힌 요약만으로는 독자가 결과를 재현하거나 검증할 수 없습니다. “공개 검증됨”으로 읽으면 안 됩니다.
  • 네 가지 연구 목표(수정 펌웨어, Lightroom 색 프로파일, AF, UI 이식)는 모두 진행 중입니다. 이 묶음에는 카메라 플래시·부팅이나 새 Lightroom 내보내기가 없습니다.
이 문서로 할 수 있는 것과 없는 것

할 수 있는 것: 어떤 실험을 어떤 조건에서 했고 무엇이 나왔는지, 한계가 무엇인지 알 수 있습니다. 근거 파일이 나중에 공개되면 해시로 여기 요약한 그 파일인지 맞춰 봅니다.

할 수 없는 것: 입력, 검사 스크립트, 실행 기록이 공개되지 않았으므로 결과를 다시 만들거나 숫자를 직접 확인할 수 없습니다. 이미 공개된 선행 근거 문서는 각 항목 끝의 링크에 있습니다.

검증과 공개의 단계

여기 실린 여덟 건은 네 단계 가운데 두 번째인 로컬 검토까지 마쳤습니다. 남은 단계는 공개 재현 패키지와 실기 검증입니다.

여덟 건 가운데 네 건은 v0.3.1의 동결 ZIP을 만든 뒤에 추가했습니다(Q7 원본 SDK의 두 조명 표 혼합, D9 인터럽트 등록과 타이머 객체의 구분, Q7 원본 DCP와 XY에서 색 표 선택, ElapsedTimer의 D9 ReloadTimer 연결). 네 목표의 전체 현황은 세 기종 연구 본부에 있습니다.

  • K-3 III

    할당기의 두 번째 RMW 워드

    일반 little-endian RAM의 고정 주소 [0x56493264, 0x56493268)에서 여섯 A32 명령이 중간의 외부 쓰기나 예외 없이 차례로 끝나면, 마지막 값은 초기 워드와 상관없이 0입니다.

    별도의 바이트 배열 모델에서도 0이 아닌 최종값이나 초기값에 따라 달라지는 반례를 찾는 질의는 모두 unsat였습니다.

    한계: 중간 바이트는 초기값에 따라 달라집니다. 기존 분류 48바이트 중 조건부로 증명한 범위는 8바이트이고 40바이트가 남았습니다. 기존 56바이트 허용 범위는 그대로 둡니다. 새 CPU 실행이나 물리 초기값을 만드는 코드의 확인은 없었습니다.

    공개 선행 근거: 기존 48바이트 분류와 첫 워드 증명

  • Q7

    DCP의 세 LUT를 원본 SDK 함수에서 실행

    고정 입력에서 원본 Adobe DNG SDK 참조 함수로 Q7 표본 42개와 항등 대조 28개를 실행했습니다. 따로 다시 실행한 로그도 일치했습니다.

    원본과 binary64 모델의 RGB 채널 최대 차이는 3.301793185528368e−7입니다. 모델 HSV를 반올림해 SDK로 변환한 RGB와의 최대 차이는 4.76837158203125e−7입니다.

    한계: 고른 합성 입력에서 관측한 최댓값입니다. 세 표는 따로따로 적용했고 조명 혼합과 RAW 렌더는 실행하지 않았습니다.

    공개 선행 근거: Q7 DCP 저장 구조

  • Q7

    조명별 HueSatMap 혼합

    고정 DCP의 두 조명 표에서 역온도 보간과 끝값 처리를 원본 SDK를 근거로 계산했습니다. 별도 계산으로 계수 관측 15건도 대조했습니다.

    한 합성 입력에서 “계수로 섞은 뒤 V를 제한한 값”과 “표마다 먼저 제한하고 섞은 값”의 차이는 0.0380834였습니다.

    한계: 정규화 HSV의 V를 다루는 수치 모형입니다. native real32 혼합, 휘도, Lightroom 출력이나 카메라 렌더와 맞는지는 미확인입니다.

    공개 선행 근거: Q7 As Shot과 프로파일별 백색점

  • K-3 II

    톤 필드의 저장과 복원

    원본의 저장 명령과 복원 명령을 따로 대조했습니다. 그 사이에 owner 슬롯을 바꾸자 기존 객체에는 0xAAAA가 남고 새 객체에 0x1254가 기록됐습니다.

    한계: 두 구간 사이의 원본 흐름, 실제 메뉴·촬영과 같은 owner 수명은 미확인입니다. 별도 selector 5 경로와는 필드 형태만 비교했으며 같은 객체 인스턴스라는 근거는 없습니다.

    공개 선행 근거: K-3 II 톤 설정 관리자

  • Q7

    원본 SDK의 두 조명 표 혼합

    이미 계산해 둔 가중치 두 개를 원본 SDK의 Interpolate에 넘겼습니다. 혼합된 표 16,200개 성분이 Decimal 기반의 단계별 float32 계산과 비트 단위로 같았습니다.

    합성 RGB 8사례에서 native 참조 함수도 실행했습니다. Adobe-model 조건의 V는 0.993945599입니다. 개별 출력을 먼저 제한한 뒤의 가중합은 0.955862082였습니다.

    한계: 가중치와 XY는 이전 기록의 값으로 고정했습니다. SDK 내부 가중치를 계측하거나 native 온도·white 추정을 실행한 결과는 아닙니다. 전체 RAW·Lightroom과 실기는 미검증입니다.

    공개 선행 근거: Q7 DCP 보간 규칙

  • K-3 III

    D9 인터럽트 등록과 타이머 객체의 구분

    슬롯 0x54785cf8이 비어 있을 때 ImageInterruptService의 outer+4가 등록되는 정적 경로를 확인했습니다. 이 배열을 쓰는 쪽은 vslot+8을 호출합니다.

    정적으로 다시 검사했을 때 원본 13개 구간과 전체 관측이 일치했습니다.

    한계: ElapsedTimer가 쓰는 객체 슬롯 0x54784f6c와는 별개입니다. 실제 등록 순서와 당시 RAM 값은 관측하지 않았고 CPU·MMIO를 실행하지 않았습니다.

    공개 선행 근거: ElapsedTimer와 두 레지스트리

  • Q7

    원본 DCP와 XY에서 색 표 선택까지

    원본 DCP를 SDK ParseExtended로 읽고 XY 다섯 개만 넣어 HueSatMapForWhite를 호출했습니다. 직접 읽은 온도·tint가 이전 수식과 같았습니다.

    native가 파싱한 두 표의 16,200개 성분은 DCP 원시 태그와, 돌려준 다섯 표의 40,500개 성분은 별도 반올림 계산과 비트 단위로 같았습니다. Adobe-model·D50의 표는 고정 가중치 실험의 표와도 일치합니다.

    한계: 가중치를 SDK에 넣지 않았습니다. 비교용 g는 별도 native 온도에서 계산한 값이며 내부 g를 계측한 값이 아닙니다. Matrix-model XY는 Adobe DCP에 넣은 가정 입력입니다. 새 RGB·RAW·Lightroom 렌더와 실기는 포함하지 않습니다.

    공개 선행 근거: 백색점 수식과 기록

  • K-3 III

    ElapsedTimer의 D9 ReloadTimer 연결

    객체 등록이 성공하고 결합이 유지되면 슬롯 0x54784f6c에 ReloadTimer가 들어갑니다. vslot+0x6c는 원본 명령 0x5326d5e8에서 0x1e0000a4의 32비트 값을 읽는 경로입니다.

    생성자가 설정의 주소 값을 객체 필드로 복사하므로 원래 스택 설정의 수명과는 따로 봐야 합니다. 원본 12개 구간과 관측 전체를 따로 다시 검사했습니다.

    한계: 생성자가 등록 결과를 분기 조건으로 쓰지 않으므로 생성자가 돌아왔다는 사실만으로 성공을 단정하지 않습니다. 객체 키 D9, 같은 객체의 IRQ 키 0x60, ImageInterruptService의 IRQ 키 D9는 서로 다릅니다. CPU·MMIO·CP15는 실행하지 않았으며 실제 순서·계수 방향·클럭·단위는 미확인입니다.

    공개 선행 근거: AF의 시간 표본과 정수 환산
