세 기종 펌웨어 연구 인계

독립 검토를 마친 로컬 연구 여덟 건의 요약입니다. 원본 검사기와 실행 기록은 로컬에 보관합니다. 이 JSON은 근거의 식별값과 범위를 담으며, 단독으로 결과를 재현할 수 없습니다. 네 연구 목표는 진행 중입니다. 이번 인계에 실기 플래시·부팅이나 새 Lightroom 내보내기는 없습니다.

독립 검토를 마친 로컬 결과

K-3 III 할당기의 두 번째 RMW 워드

일반 little-endian RAM의 고정 주소 [0x56493264, 0x56493268)에서 중간의 외부 쓰기나 예외 없이 여섯 A32 명령이 순차 완료되면 마지막 값은 초기 워드와 관계없이 0입니다. 독립 바이트 배열 모델에서도 비영 최종값과 초기값 의존 반례를 찾는 질의는 모두 unsat였습니다.

중간 바이트는 초기값에 의존합니다. 기존 분류 48바이트 중 조건부로 증명한 범위는 8바이트이고 40바이트가 남았습니다. 기존 56바이트 허용 범위를 유지했습니다. 새 CPU 실행이나 물리 초기값 생산자 검증은 없었습니다.

공개 선행 근거 · 기존 48바이트 분류와 첫 워드 증명

Q7 DCP의 세 LUT를 원본 SDK 함수에서 실행

고정 입력에서 원본 Adobe DNG SDK 참조 함수의 Q7 표본 42개와 항등 대조 28개를 검토했습니다. 독립 재실행 로그가 일치했습니다. 원본과 binary64 모델의 RGB 채널 최대 차이는 3.301793185528368e−7, 모델 HSV를 반올림해 SDK로 변환한 RGB와의 최대 차이는 4.76837158203125e−7입니다.

선택한 합성 입력의 관측 최댓값입니다. 세 표는 독립 적용했고, 조명 혼합과 RAW 렌더는 실행하지 않았습니다.

공개 선행 근거 · Q7 DCP 저장 구조

Q7의 조명별 HueSatMap 혼합

고정 DCP의 두 조명 표에서 역온도 보간과 끝값 처리를 원본 SDK에 근거해 계산했습니다. 독립 계산에서 15건의 계수 관측을 대조했습니다. 한 합성 입력에서는 계수 혼합 뒤 V를 제한하는 값과, 각 표의 결과를 먼저 제한해 혼합하는 값의 차이가 0.0380834였습니다.

정규화 HSV의 V에 대한 수치 모형입니다. native real32 혼합, 휘도, Lightroom 출력이나 카메라 렌더와의 일치는 미확인입니다.

공개 선행 근거 · Q7 As Shot과 프로파일별 백색점

K-3 II 톤 필드의 저장과 복원

원본의 분리된 저장·복원 명령을 대조했습니다. 저장과 복원 사이에 owner 슬롯을 바꾼 조건을 독립 재현하자 기존 객체에는 0xAAAA가 남았고 새 객체에 0x1254가 기록됐습니다.

두 구간 사이의 원본 흐름, 실제 메뉴·촬영과 동일한 owner 수명은 미확인입니다. 별도 selector 5 경로와는 필드 형태를 비교했으며 같은 객체 인스턴스라는 근거는 없습니다.

공개 선행 근거 · K-3 II 톤 설정 관리자

Q7 원본 SDK의 두 조명 표 혼합

이전에 계산한 두 가중치를 원본 SDK Interpolate에 전달했습니다. 실제 혼합 표 16,200개 성분은 독립 Decimal 기반 단계별 float32 계산과 비트 단위로 일치했습니다. 8개 합성 RGB 사례에서 native 참조 함수도 실행했습니다. Adobe-model 조건의 V는 0.993945599이며 개별 출력 제한 후 가중합은 0.955862082였습니다.

가중치와 XY는 선행 기록으로 고정했습니다. SDK 내부 가중치를 계측하거나 native 온도·white 추정을 실행한 결과는 아닙니다. 전체 RAW·Lightroom과 실기는 미검증입니다.

공개 선행 근거 · Q7 DCP 보간 규칙

D9 인터럽트 등록과 타이머 객체의 구분

슬롯 0x54785cf8이 비어 있을 때 ImageInterruptService의 outer+4가 등록되는 정적 경로를 확인했습니다. 이 배열의 소비자는 vslot+8을 호출합니다. 정적 재검사에서 원본 13개 구간과 전체 관측이 일치했습니다.

ElapsedTimer가 사용하는 객체 슬롯 0x54784f6c와 별개입니다. 실제 등록 순서와 당시 RAM 값은 관측하지 않았고 CPU·MMIO를 실행하지 않았습니다.

공개 선행 근거 · ElapsedTimer와 두 레지스트리

Q7 원본 DCP와 XY에서 색 표 선택까지

원본 DCP를 SDK ParseExtended로 읽고 다섯 XY만 공급해 HueSatMapForWhite를 호출했습니다. 직접 읽은 온도·tint가 선행 수식과 같았습니다. native가 파싱한 두 표의 16,200개 성분은 DCP 원시 태그와, 반환한 다섯 표의 40,500개 성분은 독립 반올림 계산과 비트 단위로 일치했습니다. Adobe-model·D50의 표는 고정 가중치 실험과도 같았습니다.

가중치를 SDK에 입력하지 않았습니다. 비교용 g는 별도 native 온도에서 계산한 값이며 내부 g를 계측한 값은 아닙니다. Matrix-model XY는 Adobe DCP에 공급한 가정 입력입니다. 새 RGB·RAW·Lightroom 렌더와 실기는 포함하지 않습니다.

공개 선행 근거 · 백색점 수식과 기록

ElapsedTimer의 D9 ReloadTimer 연결

객체 등록에 성공하고 결합이 유지되면 슬롯 0x54784f6c에 ReloadTimer가 들어갑니다. vslot+0x6c는 원본 명령 0x5326d5e8에서 0x1e0000a4의 32비트 값을 읽는 경로입니다. 생성자가 설정의 주소 값을 객체 필드로 복사하므로 원래 스택 설정의 수명과 구분됩니다. 12개 원본 구간과 관측 전체를 독립 재검사했습니다.

등록 결과를 생성자가 분기 조건으로 쓰지 않아 생성자 복귀만으로 성공을 단정하지 않습니다. 객체 키 D9, 같은 객체의 IRQ 키 0x60, 앞선 ImageInterruptService의 IRQ 키 D9는 각각 별도입니다. CPU·MMIO·CP15는 실행하지 않았으며 실제 순서·계수 방향·클럭·단위는 미확인입니다.
