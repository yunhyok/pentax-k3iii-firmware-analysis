어떤 블록을 그대로 쓰는가

LZ 복사 토큰은 상위 5비트와 하위 8비트를 합쳐 뒤로 참조할 거리를 지정한다. 유효 거리는 1–8191바이트다. 복사 길이가 거리보다 길면 같은 블록에서 방금 생성한 출력도 이어서 복사한다. 따라서 블록 시작 직전의 최대 8191바이트와 해당 블록의 목표 출력이 원본과 같으면, 기존 토큰을 그대로 디코딩해도 같은 바이트가 나온다. 프로젝트 디코더 · 독립 디코더의 토큰 형식

선택한 블록을 바꾼 뒤 스트림 길이가 홀수면, 교체 시 크기 변화가 홀수인 미교체 LZ 블록 중 변화량이 가장 작은 것을 추가로 stored로 바꾼다. 길이가 짝수이면서 4의 배수가 아니면, 교체된 stored 조각 하나를 둘로 나누어 2바이트 헤더를 하나 더 붙인다. 이번 후보에는 추가 교체가 한 번 있었고 분할은 필요하지 않았다. 정렬 처리 · 정렬·경계 합성 테스트

  • Unicorn에서 원본 ARM 함수로 원본과 후보를 각각 네 번 검사했다. 두 이미지 모두 정상 헤더·외부 체크섬은 1, 프로젝트 필드를 바꾼 입력은 0, 매직 값을 바꾼 입력은 0, 정상 내부 체크섬은 1이었다. 체크섬 루프는 전체 버퍼를 사용했고, 거절 분기에서 진단 출력만 생략했다. 원본 ARM 검사 · 8개 반환값과 검사 범위
  • 합성 테스트 8개로 무변경 바이트 보존, 참조 거리 8191·8192의 경계, 겹치는 복사, 홀짝 정렬, 큰 블록 분할, 잘못된 길이·범위 거절, 출력 덮어쓰기 방지와 쓰기 실패 정리를 확인했다. 재현 테스트
