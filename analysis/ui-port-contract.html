공통으로 구현할 동작과 다음 실험

제안 화면을 열 때 대상 기종의 현재값을 읽는다. 선택 중에는 보류값과 표시만 바꾼다. 같은 값을 확정할 때도 해당 기종의 setter와 콜백 조건을 보존한다. 취소할 때는 대상 기종의 닫기와 통지 동작을 보존한다. 버튼 매핑, 이벤트 번호와 설정값, 리소스 형식은 기종별로 확인해 적용한다.

K-3 III에서 선택 가능한 행을 확정하면 setter를 호출한다. 설정 레코드와 캐시가 모두 새 값과 같으면 setter는 레코드 기록과 observer 생성을 생략한다. K-3 II는 같은 값으로 확정해도 RAM의 현재값과 미러에 각각 기록한다. 별도 저장 단계에서 준비한 섹터의 내용이 기존과 같으면 쓰기 요청을 생략한다. K-3 III setter 조건 · K-3 II 화면 상태 · K-3 II 섹터 쓰기 조건

  1. 두 K-3 기종에서 물리 입력이 색공간 위젯의 논리 이벤트로 이어지는 경로를 확인한다. Q7은 E3 화면을 기존 입력·설정 경로에 연결해 검증한다.
  2. 양방향 변경·확정, 변경 후 취소, 같은 값 확정에서 setter 호출, RAM 기록, 콜백·하위 요청과 섹터 쓰기 요청을 구분해 기록한다. 창을 닫고 다시 열 때의 값과 재부팅 후 값은 따로 확인한다.
  3. 그 화면의 무효화부터 실제 문자·포커스 렌더러를 거쳐 출력 버퍼까지 추적한다. 각 기종의 출력 형식과 stride를 사용해 예상 영역과 인접 바이트를 대조한다. 초기 시험의 표식은 새로 그린다.

이 계약은 확인한 접점을 바탕으로 한 화면 설계다. 이식 화면의 실행, 물리 입력부터 LCD 출력까지의 확인, 설정의 영속 저장은 각 기종에서 검증해야 한다. 상태·주소·시험 조건
