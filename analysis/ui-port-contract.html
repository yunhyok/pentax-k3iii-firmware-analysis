공통으로 구현할 동작과 다음 실험

제안 화면을 열 때 대상 기종의 현재값을 읽는다. 선택 중에는 보류값과 표시만 바꾼다. 달라진 값을 확정하면 대상 설정 인터페이스에 한 번 쓰고 다시 읽는다. 취소하거나 같은 값을 확정하면 쓰지 않는다. 버튼 매핑, 숫자 이벤트·값, 리소스 형식은 기종별로 확인해 적용한다.

  1. 공식 메뉴 위치에서 실제 색공간 항목의 입력을 추적한다. 두 방향의 선택과 확정·취소에 대해 이벤트 값, 화면 객체, 설정 읽기·쓰기, 로케일 리소스의 주소를 기록한다.
  2. 원본 구간을 합성 상태로 재실행한다. 두 값 사이를 왕복해 반영 횟수와 다시 열었을 때의 값을 확인한다. 취소하거나 같은 값을 확정했을 때는 쓰기가 없는지 확인한다. 원본 동작이 제안과 다르면 차이를 기록한다.
  3. 그 화면의 무효화부터 실제 문자·포커스 렌더러를 거쳐 출력 버퍼까지 추적한다. 각 기종의 출력 형식과 stride를 사용해 예상 영역과 인접 바이트를 대조한다. 초기 시험의 표식은 새로 그린다.
