RTOS 명령과 셸 안내

카메라 본체는 실시간 운영체제(RTOS) 위에서 돌며, 내부 점검·개발용 셸 명령 957개를 가지고 있습니다. 이 명령들이 무엇을 담당하고, 촬영·AF 요청이 어떻게 하드웨어까지 이어지는지를 모아 봅니다.

핵심 요약

  • 이 주제는 “명령이 무엇을 담당하는가(분류) → 요청이 어디로 가서 무엇을 움직이는가(디스패처·셔터·AF) → 바깥에서 셸에 입력할 수 있는가(SD 스크립트)”로 이어집니다.
  • 명령 분류와 호출표, SAD·SSD 상관 함수는 바이트 대조로 확인했고, 요청 처리 경로는 원본 명령을 읽어 추적했습니다.
  • 이벤트에서 실제 셔터·AF 동작으로 가는 런타임 상태 전이와, USB로 셸에 들어가는 경로는 아직 확인하지 못했습니다. 카메라에서 실행한 것은 없습니다.

한눈에 보기

중심에 셸 명령 957개가 있습니다. 명령의 분류, 촬영·AF 요청의 처리, SD 스크립트를 통한 셸 입력을 각각 다른 문서가 다룹니다.

배경 지식

RTOS
실시간 운영체제입니다. 정해진 시간 안에 동작해야 하는 카메라 제어를 맡으며, 이 카메라에서는 Linux와 함께 돕니다.
셸 명령
문자열 이름과 처리 함수를 짝지어 둔 점검·개발용 목록입니다. 이름을 입력하면 해당 함수를 부릅니다. 펌웨어의 SHELLCMD 레코드에 957개가 있습니다.
디스패처
요청 메시지를 받아 담당 작업으로 나눠 보내는 부분입니다. 촬영·AF 요청이 공통 메시지로 여기 모였다가 각 이벤트로 갈라집니다.
이벤트 큐
처리할 일을 순서대로 담아 두는 대기열입니다. 요청이 이벤트로 바뀌어 큐에 들어가면, 소비 함수가 꺼내 제어 객체로 넘깁니다.
SAD·SSD
두 신호의 차이를 재는 기본 연산(차이의 절댓값 합·제곱 합)입니다. NEON 명령으로 빠르게 계산하며, 위상차 AF의 상관에 쓰입니다.
TTL 스크립트와 sendln
TTL은 터미널 프로그램 Tera Term의 매크로 언어이고, sendln은 한 줄을 보내는 명령입니다. SD의 스크립트가 이를 통해 셸 명령을 넣습니다. sendln 매뉴얼
eMMC
본체에 붙박인 내장 플래시 저장장치입니다. 꺼낼 수 있는 SD 카드와 달리 부트 영역과 일반 영역이 하드웨어로 나뉩니다.

    분류와 호출 관계

    셸 명령 957개는 무엇을 담당하는가?

    17개 기능군으로 나누고, 촬영·AF·영상처리 명령의 호출 경로를 기계어와 대조했습니다.

    디스패처·셔터·AF

    촬영·AF 요청이 어디로 가서 무엇을 움직이는가?

    공통 메시지가 이벤트로 갈라지고, 셔터가 GPIO에 쓰는 지점과 AF 상관 연산을 추적했습니다.

  • 3

    SD 셸 입력·백업

    바깥에서 셸에 입력할 수 있는가? 백업은 어디에 쓰는가?

    SD 스크립트가 셸 명령을 실행하는 경로를 확인했고, 보정 백업이 내부 eMMC에도 쓴다는 것을 밝혔습니다.
