# v0.3.0 — K-3 III 원본 실행과 색·AF·UI 연구

펌웨어 2.20의 부팅과 RTOS, AF, 화면 그리기를 PC에서 재현한 결과를 추가했습니다. Lightroom 비교에는 같은 RAW에서 얻은 실제 TIFF와 별도의 독립 장면을 사용했습니다. 수정 펌웨어의 카메라 수용·부팅과 독립 복구는 확인하지 못했습니다.

## 재구축과 부팅

- 기존 추적의 다른 48바이트를 분류하고, 선택한 4바이트의 최종값이 초기 32비트와 무관함을 별도 수동 모형으로 증명했습니다. 중간 바이트는 초기값에 의존합니다. 다른 44바이트와 실제 초기 기록자는 미확정이며 기존 56바이트 허용 목록을 유지했습니다. [추적 분류와 모형](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/rmw-scope/report.html)

- Stubby의 ROMFS 선택과 복사, INITFS 헤더와 DTB 준비를 원본 명령 구간별로 확인했습니다. 설정에서 할당과 첫 task stack으로 이어지는 일부 경로, 레지스트리 할당·이름 조회도 재현했습니다. RMW의 8바이트 결과는 명시한 전제 아래 수동 모형으로 검증했습니다. 나머지 초기 RAM의 출처와 부팅의 실제 호출 순서는 미확인입니다. [재구축 안내](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/guide-rebuild.html) · [RMW 모형 검증](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/rmw-proof/report.html)

## Lightroom 색 프로파일

- 공개 Adobe DNG SDK Build 2768의 오브젝트 276개를 새로 빌드해 고정 DNG의 Stage 2 활성 영역 25,891,840개를 전수 대조했습니다. 두 배열과 실행 로그가 최초 실행과 일치했습니다. XMP 처리를 끈 이 실행의 범위는 Stage 2까지이며, Adobe 제품 내부 처리와 동일하다고 주장하지 않습니다. [원본 SDK Stage 2와 재빌드](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/lightroom-sdk-stage2.html)

- 톤 후보를 차트와 독립 장면에 적용하고 Lightroom 출력과 비교했습니다. 후보의 차트 최대 ΔE00는 0.8918로 사전 한도 0.75를 넘었습니다. K-3 III와 Q7의 Bright 스튜디오 비교는 각각 정합을 통과한 국소 영역을 기준으로 해석합니다. 카메라 JPEG와 같은 색을 재현하는 최종 프로파일은 아직 확보하지 못했습니다. [독립 장면 비교](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/color-scene-transfer.html) · [합성 톤 시험](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/lightroom-composed-tone.html) · [Bright 스튜디오 비교](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/lightroom-studio-baseline.html)
- K-3 III PEF와 변환 DNG의 CFA 샘플 26,628,096개가 일치했습니다. 변환 DNG의 WhiteLevel은 원본 PEF의 MakerNote에 기록된 값과 달랐습니다. 공개 SDK 정규화 수식에서는 DNG 기본 크롭의 8,530개가 65,535에 이릅니다. 이 수치는 Lightroom의 실제 렌더링 비교와 별개입니다. [샘플 보존](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/lightroom-cfa-preservation.html) · [CFA 범위](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/lightroom-cfa-range.html)

## AF와 UI

- 비회전 sRGB 전송의 일곱 좌표에서 소스 읽기·32비트 쓰기·전체 RAM 프레임을 대조했습니다. 여섯 좌표는 호출자 스택에서 공급했으며 실제 메뉴의 viewport는 확인하지 못했습니다. [일곱 클립 조건](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/colorspace-clip.html)

- Joint에서 PafMotor, AfMotorDriver와 PWM으로 이어지는 객체 연결을 확인했습니다. 드라이버 콜백과 PWM 레코드의 부호·절삭·제한을 별도 ARM 실행으로 대조했습니다. 센서 입력, 실제 모터의 역할과 이동, 광학 초점은 확인되지 않았습니다. [AF 드라이버 연결](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/af-driver-pwm.html) · [PWM 요청과 정수 변환](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/af-pwm-parameters.html)
- 색공간 행의 아이콘, 글꼴 준비, sRGB 측정과 32비트 RAM 표면으로의 픽셀 전송을 재현했습니다. Q7의 인덱스 팔레트와 배율 계산을 별도 근거로 비교했습니다. K-3 II·Q7에 이식한 화면의 실제 입력·LCD·재부팅은 검증하지 못했습니다. [sRGB 글자 전송](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/colorspace-text.html) · [기종 간 비교](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/cross-ui-text.html)
