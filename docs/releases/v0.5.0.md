# v0.5.0 — 실제 펌웨어 대조, 펌웨어 색 표와 Custom Image 16종 프로파일 공개

실제 펌웨어 2.20으로 지금까지의 검증기를 모두 다시 돌리고, 같은 펌웨어에서 카메라의 색 처리 경로를 확정한 릴리스입니다. 펌웨어에서 읽은 색 표와 Custom Image 16종의 Lightroom용 색 프로파일(DCP)을 공개합니다. 펌웨어 없이 같은 계산을 하는 엔진과 프로파일 생성 도구도 넣었습니다. Lightroom에서는 아직 재지 않았습니다.

문서: https://yunhyok.github.io/pentax-k3iii-firmware-analysis/

## 새로 생긴 것

- **실제 펌웨어로 검증기를 다시 돌렸습니다.** 그동안의 검수는 펌웨어 없이 했습니다. 리코 공식 페이지에서 받은 `fwdc233b.bin`(2.20)의 해시가 `evidence.json`과 같음을 확인하고, 펌웨어를 읽는 검증기와 재현 스크립트 101개를 다시 돌렸습니다. 101개 모두 결과를 재현했고, 커밋된 근거 JSON 107개 가운데 104개는 바이트까지 같았습니다. 나머지 3개는 입력 해시 필드만 달랐습니다(잘라 낸 레코드 대신 전체 파일로 돌린 차이). 비공개 입력, Windows 전용 컴파일러, Q7 펌웨어가 필요한 네 개는 돌리지 못했습니다.
- **색 처리 경로를 펌웨어로 확정했습니다.** 카메라의 색 설정 루틴 전체를 PC 에뮬레이터에서 실행해 19개 Custom Image의 하드웨어 설정값을 얻었습니다. 색 행렬의 출력은 선형 sRGB이고, 감마 곡선의 출력은 sRGB로 부호화된 값입니다. 노출 배율은 펌웨어의 BaselineExposure 식에서 읽었습니다. [펌웨어로 확정한 색 처리 경로](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/firmware-color-pipeline.html)
- **펌웨어 색 표를 공개했습니다.** `analysis/k3iii-color-tables.json`에 행렬 34개, 채도·색상 행렬 묶음, 감마 기준 곡선, 채도 억제 값, 조색 오프셋, DNG 행렬 표, Custom Image별 출고 설정, Auto Select 장면 표가 있습니다. `tools/export_color_tables.py`가 풀어 둔 펌웨어 이미지에서 이 파일을 씁니다.
- **Custom Image 16종의 프로파일을 공개했습니다.** `profiles/k3iii/k3iii-firmware-<mode>.dcp`입니다(Natural, Bright, Portrait, Landscape, Vibrant, Radiant, Muted, Flat, Bleach Bypass, Reversal Film, Monochrome, SATOBI, HARUBENI, KATEN, KYUSHU, FUYUNO). 하나가 약 950 KB이고 16개를 합하면 약 15 MB입니다. Auto Select, Cross Processing, Gold는 프로파일이 없습니다. [K-3 Mark III 색 프로파일 모음](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/color-profiles.html)
- **프로파일은 출고 설정으로 만들었습니다.** Custom Image마다 출고 설정이 다릅니다. 펌웨어의 출고 설정 표(`0x53c174e0`)에서 읽었습니다. 예를 들어 Bright는 대비 +1, Flat은 대비 −4, Radiant는 키 +2와 대비 +3입니다. 표의 행과 Custom Image의 대응은 간접 근거로 정했습니다. 행 번호를 Custom Image로 바꾸는 코드는 찾지 못했습니다.
- **RAW의 설정 기록을 찾았습니다.** 메이커노트 태그 0x0247에 부호 있는 16비트 값 24개가 있습니다. 채도, 색상, 키, 대비, 대비(하이라이트), 대비(섀도), 샤프니스 순이고 열세 번째 값이 조색입니다. Bright 표본 RAW에는 대비 +1, 샤프니스 +1이 기록돼 있었습니다. `tools/compare_camera_jpeg.py`가 이 기록을 읽어 씁니다.
- **조색은 프로파일에 넣지 못합니다.** Muted, Bleach Bypass, HARUBENI는 색상 대신 조색을 씁니다. 펌웨어는 채도 억제 뒤 Cb·Cr에 상수를 더하므로 회색도 물듭니다. DCP의 색상·채도 표는 채도를 곱하는 방식이라 회색을 물들일 수 없습니다. Bleach Bypass와 HARUBENI 프로파일은 조색을 끈 카메라와 같습니다. 출고 설정은 각각 그린과 레드 조색입니다.
- **프로파일 설계를 바꿨습니다.** ForwardMatrix에는 모든 Custom Image가 함께 쓰는 공통 행렬을 넣었습니다. 모드 행렬, 채널별 감마 적용, 카메라 출력 색역의 클리핑, YC 변환, 휘도에 따른 채도 억제는 ProfileLookTable(90×30×30)에 넣었습니다. ProfileToneCurve는 출고 설정의 감마 곡선입니다. 이전 설계는 채도를 올리는 모드(Bright, Landscape, Vibrant, Radiant, HARUBENI, KATEN, Portrait)에서 채도가 높은 파랑을 검게 그렸습니다. 모델과의 차이는 CIEDE2000 40~56까지 났습니다. 이전 설계의 “평균 0.05”는 이 문제가 없는 Natural에서만 잰 값이었습니다.
- **펌웨어 없이 도는 엔진과 생성 도구를 넣었습니다.** `tools/k3iii_color_engine.py`는 펌웨어와 같은 정수 계산을 하고 색 표 JSON만 읽습니다. 펌웨어 에뮬레이터와 10,087개 사례를 대조했고 불일치는 0개였습니다(18개 Custom Image × 설정 98개(Cross Processing은 97개) × 색공간 2 = 3,526개, Natural의 톤 설정 6,561개 전부). `tools/make_k3iii_profile.py`는 펌웨어 없이 DCP를 만듭니다. `--from-raw`로 PEF·DNG에 기록된 Custom Image, 설정, 색공간을 읽을 수 있습니다. 주지 않은 설정은 카메라의 출고 값을 씁니다. 같은 PC에서 엔진으로 만든 16개와 펌웨어로 만든 16개는 바이트까지 같습니다. [프로파일 생성 프로그램 타당성 검토](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/profile-maker-feasibility.html)
- **카메라 JPEG과 비교했습니다.** 같은 RAW로 카메라가 기록한 JPEG과 PC에서 비교한 평탄 블록의 평균 ΔE00은 다음과 같습니다(DCP를 Adobe DNG SDK의 참조 처리 순서로 적용, 맞춘 매개변수 없음). Natural(설정 모두 0)은 모델 0.852, 프로파일 0.904입니다. Bright(RAW에 기록된 대비 +1)는 모델 0.907, 프로파일 0.907입니다. 이전에 적은 Bright 1.382는 설정을 모두 0으로 놓고 계산한 값이었습니다.
- **프로파일을 모델과 대조했습니다.** `tools/check_profile_accuracy.py`가 16종 각각을 색 모델과 비교합니다. 무작위 장면 색 60,000개에서 카메라 색역 안쪽 색의 평균 ΔE00은 0.02~0.11입니다(Natural 0.044, 가장 큰 Radiant 0.112). 모든 분류와 프로파일을 통틀어 가장 큰 값은 3.8(FUYUNO)입니다. LookTable과 톤 곡선 계산은 DNG SDK 1.7.1의 해당 루틴과 16종 모두 대조했습니다. sRGB 8비트 코드값 차이는 평균 0.017~0.062, 최대 2.02(Muted)입니다.
- **새 문서 18개**: 새 사이트 절 “프로파일”에 [K-3 Mark III 색 프로파일 모음](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/color-profiles.html), 모드별 프로파일 문서 16개, [프로파일 생성 프로그램 타당성 검토](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/profile-maker-feasibility.html)가 있습니다. 모드별 문서에는 리코의 공식 설명과 출처(`analysis/k3iii-profile-notes.json`)를 실었습니다.
- **새 도구와 근거 파일**: `tools/k3iii_tuning_emulator.py`, `tools/firmware_color_model.py`, `tools/build_firmware_dcp.py`, `tools/check_firmware_color.py`, `tools/compare_camera_jpeg.py`, `tools/check_dcp_against_sdk.py`와 `tools/dng_sdk_harness.cpp`, `tools/export_color_tables.py`, `tools/k3iii_color_engine.py`, `tools/check_color_engine.py`, `tools/make_k3iii_profile.py`, `tools/check_profile_accuracy.py`, `tools/build_profile_pages.py`, `tests/test_firmware_color_model.py`, `tests/test_color_engine.py`, `analysis/firmware-color-pipeline.json`, `analysis/firmware-color-validation.json`, `analysis/k3iii-color-tables.json`, `analysis/k3iii-color-engine-checks.json`, `analysis/k3iii-profile-accuracy.json`, `analysis/k3iii-profile-data.json`, `analysis/k3iii-profile-notes.json`. `tools/profile_bridge.py`는 `ProfileEmbedPolicy`, `ProfileCopyright`, `BaselineExposureOffset`, `DefaultBlackRender` 태그를 받습니다. 펌웨어로 확인하는 도구에는 `unicorn==2.1.4`와 `numpy`, 비교에는 `rawpy`와 `opencv-python-headless`가 필요합니다.

## 기존 문서에서 바뀐 것

- [Lightroom 색 프로파일 안내](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/guide-lightroom.html): 요약, 현황 표, 읽는 순서 맨 앞에 펌웨어 DCP를 넣었습니다. 프로파일을 받는 곳과 새 수치를 적었습니다. 시험 DCP와 Adobe 프로파일을 실제 Lightroom으로 잰 이전 결과는 "이전 방식"으로 남겼습니다.
- [색 처리 안내](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/guide-color.html): 새 문서를 지도와 읽는 순서에 넣고, "하드웨어의 처리 순서와 행렬의 색공간은 모른다"는 서술을 지금 아는 것으로 바꿨습니다.
- `lightroom-bridge.html`의 현황 표, `color-algorithms.html`의 미확인 목록(본문은 그대로 두고 "추가 확인" 상자를 더함), `color-lightroom.html`·`pipeline-report.html`의 낡은 문장, 첫 화면과 README를 고쳤습니다. 색 표의 값을 공개하지 않는다는 문장은 공개한 파일을 가리키도록 바꿨습니다.
- `verify_bank_writers.py`: Windows 전용 환경 변수 `TEMP`를 읽던 줄을 지웠습니다. Linux·macOS에서도 문서의 명령으로 돌아갑니다.

검증기 실행 결과 전체와 고친 서술 목록은 [`docs/audit/2026-11-firmware-verification.md`](https://github.com/yunhyok/pentax-k3iii-firmware-analysis/blob/main/docs/audit/2026-11-firmware-verification.md)에 있습니다.

## 알아 둘 점

- **공개 범위가 바뀌었습니다.** 펌웨어에서 읽은 색 표와 프로파일 16종을 공개합니다. 원본 펌웨어 파일과 제조사 코드의 디컴파일 결과는 여전히 공개하지 않습니다. 리코의 펌웨어 이용 조건에는 복제, 역분석, 양도를 제한하는 조항이 있습니다. 색 표를 공개한 것은 저장소 소유자의 결정입니다.
- **Lightroom은 실행하지 않았습니다.** 위 수치는 PC에서 DNG SDK의 참조 처리 순서를 Python으로 다시 구현해 계산한 값입니다. Lightroom은 자체 처리 버전과 노출 처리를 쓰므로 실제 Lightroom 측정이 다음 단계입니다. 이전에 실제 Lightroom으로 잰 값(행렬 후보 2.028, Camera Bright 1.421)과는 재는 방법이 달라 순위를 매기지 않습니다.
- **비교 범위가 좁습니다.** 공개 표본 두 장(ISO 100)이고 Natural(설정 모두 0)과 Bright(대비 +1)만 비교했습니다. 표본을 찍은 카메라 펌웨어는 1.01과 1.10이고 분석한 것은 2.20입니다. 다른 ISO·조명, 나머지 14개 프로파일, 키·하이라이트 대비·섀도 대비 설정은 카메라 출력과 비교하지 않았습니다.
- 조색, 섀도·하이라이트 보정, 클래리티, 렌즈 보정, 노이즈 감소, 샤프닝, 디지털 필터는 프로파일에 들어가지 않습니다. 무채색 평탄 블록에서 모델은 카메라 JPEG보다 L* 0.2~0.5 어둡습니다(8비트 한 단계 안팎). 원인은 찾지 못했고 섀도 보정 자동을 의심합니다.
- 다축 색 보정 단계와 화이트밸런스 단계는 추적하지 않았습니다.
- 이 저장소에는 여전히 원본 펌웨어, 제조사 코드, 카메라에 넣을 수 있는 펌웨어가 없습니다. 모든 분석은 PC에서 했습니다.
