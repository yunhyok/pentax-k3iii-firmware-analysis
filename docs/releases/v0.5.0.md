# v0.5.0 — 실제 펌웨어 대조와 펌웨어 값으로 만드는 색 프로파일

실제 펌웨어 2.20으로 지금까지의 검증기를 모두 다시 돌리고, 같은 펌웨어에서 카메라의 색 처리 경로를 확정한 릴리스입니다. K-3 Mark III는 이제 자기 펌웨어 사본으로 Lightroom용 색 프로파일(DCP)을 만들 수 있습니다. 프로파일 파일은 넣지 않았고, Lightroom에서는 아직 재지 않았습니다.

문서: https://yunhyok.github.io/pentax-k3iii-firmware-analysis/

## 새로 생긴 것

- **실제 펌웨어로 검증기를 다시 돌렸습니다.** 그동안의 검수는 펌웨어 없이 했습니다. 리코 공식 페이지에서 받은 `fwdc233b.bin`(2.20)의 해시가 `evidence.json`과 같음을 확인하고, 펌웨어를 읽는 검증기와 재현 스크립트 101개를 다시 돌렸습니다. 101개 모두 결과를 재현했고, 커밋된 근거 JSON 107개 가운데 104개는 바이트까지 같았습니다. 나머지 3개는 입력 해시 필드만 달랐습니다(잘라 낸 레코드 대신 전체 파일로 돌린 차이). 비공개 입력, Windows 전용 컴파일러, Q7 펌웨어가 필요한 네 개는 돌리지 못했습니다.
- **색 처리 경로를 펌웨어로 확정했습니다.** 카메라의 색 설정 루틴 전체를 PC 에뮬레이터에서 실행해 19개 Custom Image의 하드웨어 설정값을 얻었습니다. 색 행렬의 출력은 선형 sRGB이고, 감마 곡선의 출력은 sRGB로 부호화된 값입니다. 노출 배율은 펌웨어의 BaselineExposure 식에서 읽었습니다. [펌웨어로 확정한 색 처리 경로](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/firmware-color-pipeline.html)
- **펌웨어 값으로 DCP를 만드는 도구를 넣었습니다.** `tools/build_firmware_dcp.py`가 Custom Image 16종의 프로파일을 만듭니다(ForwardMatrix, 톤 곡선, LookTable, BaselineExposureOffset). Auto Select, Cross Processing, Gold는 지원하지 않습니다. [펌웨어 값으로 만드는 색 프로파일](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/firmware-dcp.html)
- **카메라 JPEG과 비교했습니다.** 같은 RAW로 카메라가 기록한 JPEG과 PC에서 비교한 평탄 블록의 평균 ΔE00은 Natural 0.90, Bright 1.38입니다(DCP를 Adobe DNG SDK의 참조 처리 순서로 적용, 맞춘 매개변수 없음). 펌웨어 모델 자체는 0.85와 1.38이고 프로파일과 모델의 차이는 0.05 안팎입니다. LookTable과 톤 곡선 계산은 DNG SDK 1.7.1의 해당 루틴과 대조해 sRGB 8비트 한 단계의 0.41 안에서 같았습니다.
- **새 도구와 근거 파일**: `tools/k3iii_tuning_emulator.py`, `tools/firmware_color_model.py`, `tools/check_firmware_color.py`, `tools/compare_camera_jpeg.py`, `tools/check_dcp_against_sdk.py`와 `tools/dng_sdk_harness.cpp`, `tests/test_firmware_color_model.py`, `analysis/firmware-color-pipeline.json`, `analysis/firmware-color-validation.json`. `tools/profile_bridge.py`는 `ProfileEmbedPolicy`, `ProfileCopyright`, `BaselineExposureOffset`, `DefaultBlackRender` 태그를 받습니다. 필요한 패키지는 `unicorn==2.1.4`와 `numpy`, 비교에는 `rawpy`와 `opencv-python-headless`입니다.

## 알아 둘 점

- **프로파일 파일은 이 릴리스에 없습니다.** 저장소에는 생성 도구만 있고 프로파일, 펌웨어, 계수 표는 없습니다. 리코에서 받은 자기 펌웨어로 만들고, 만든 DCP에는 그 사본에서 나온 값이 들어 있습니다.
- **Lightroom은 실행하지 않았습니다.** 위 수치는 PC에서 DNG SDK의 참조 처리 순서로 계산한 값입니다. Lightroom은 자체 처리 버전과 노출 처리를 쓰므로 실제 Lightroom 측정이 다음 단계입니다. 이전에 실제 Lightroom으로 잰 값(행렬 후보 2.028, Camera Bright 1.421)과는 재는 방법이 달라 순위를 매기지 않습니다.
- **비교 범위가 좁습니다.** 공개 표본 두 장(ISO 100)이고 Natural과 Bright만 비교했습니다. 표본을 찍은 카메라 펌웨어는 1.01과 1.10이고 분석한 것은 2.20입니다. 다른 ISO·조명과 나머지 14개 모드는 비교하지 않았습니다.
- 섀도·하이라이트 보정, 렌즈 보정, 노이즈 감소, 샤프닝은 프로파일에 들어가지 않습니다. 카메라 JPEG은 무채색 영역에서 계산보다 8비트 한두 단계 밝았고 원인은 찾지 못했습니다.
- 이 저장소에는 여전히 원본 펌웨어, 제조사 코드, 카메라에 넣을 수 있는 펌웨어가 없습니다. 모든 분석은 PC에서 했습니다.
