# v0.3.1 — K-3 III SDK Stage 3·AF 시간 입력·UI 표면

고정 DNG의 Adobe SDK Stage 3 실행과, 펌웨어 2.20의 AF 상태·시간 입력 및 UI 그리기 표면을 추가했습니다. 각 관측은 독립 검토와 본부 재현을 거쳤으며 실제 카메라에서 수정 펌웨어를 부팅한 결과는 아닙니다.

- SDK Stage 3의 카메라 RGB 77,675,520개를 RGGB 보간 모형과 전수 대조해 일치했습니다. 새 SDK 빌드와 기존 오브젝트 재사용 경로도 같은 배열을 만들었습니다. 이 범위에는 화이트밸런스·프로파일·톤·Lightroom 렌더링이 포함되지 않습니다. [SDK Stage 3](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/lightroom-sdk-stage3.html)
- PafMotor 상태 바이트의 22개 직접 저장과 적응형 문턱에 공급되는 ElapsedTimer 표본을 추적했습니다. 원본의 unsigned 차이 계산과 정수 환산을 확인했지만 물리 시간 단위, 실제 클록·렌즈 이동·광학 초점은 확인하지 못했습니다. [상태 생산자](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/af-state-producers.html) · [적응형 입력](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/af-adaptive-input.html)
- 부모의 클립 경계가 텍스트 설정으로 복사되는 경로와 Canvas의 표면 포인터가 StringView에 전달되는 조건을 추적했습니다. 타입 5 전송은 32비트 워드 단위 행 간격을 사용합니다. 실제 메뉴 객체, 입력 버퍼 할당·치수와 LCD는 미확인입니다. [viewport 생산자](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/ui-viewport-producers.html) · [그리기 표면](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/ui-surface-producers.html)

다음 연구는 SDK 보간 이후의 백색점·색 표·톤을 단계별로 대조하고, AF 서비스의 실제 시간 단위와 UI 입력 버퍼의 원본 생산자를 확인하는 일입니다. 전체 재빌드·수정 이미지 수용·부팅과 독립 복구는 계속 미검증입니다. [세 기종 연구 현황과 다음 과제](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/research-program.html)

ZIP은 v0.3.0의 연구와 새 코드·문서를 포함합니다. 원본 펌웨어·RAW·상용 LUT·SDK 전체 소스·실행 파일과 카메라 설치용 이미지는 포함하지 않습니다. 별도 입력으로 재현하며 ZIP은 함께 제공하는 SHA256SUMS.txt로 확인할 수 있습니다.

독립 검토를 마친 후속 실험 네 건은 [연구 인계](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/research-checkpoint.html)에 요약했습니다. 이 요약의 근거 해시는 로컬 기록을 식별하며, 별도 공개 재현 패키지는 아직 준비 중입니다.
