# v0.4.0 — 새 문서 검수와 문장 다듬기

v0.3.0부터 v0.3.2까지 올라온 문서를 검수해 다른 문서와 같은 형식으로 다시 쓰고, 사이트 전체의 문장을 다듬은 릴리스입니다. 새로운 분석 결과는 없습니다.

문서: https://yunhyok.github.io/pentax-k3iii-firmware-analysis/

## 바뀐 것

- **새 문서 35쪽을 다시 썼습니다.** Lightroom 12쪽, AF 9쪽, UI 7쪽, 재구축 4쪽, 부팅·업데이트·시작 3쪽입니다. 요약과 확인한 범위를 맨 앞에 두고, 배경 설명과 그림을 넣고, 주소·해시는 접어 두었습니다. 본문 뒤쪽에 있던 한계(장면 한 장, 조명 하나, 다른 펌웨어 버전의 표본, 합성 입력)를 요약으로 올렸습니다.
- **주제 안내 문서 세 편을 새로 썼습니다.** [Lightroom 색 프로파일](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/guide-lightroom.html), [AF와 렌즈 제어](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/guide-af.html), [UI와 화면 자원](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/guide-ui.html)입니다. 주제 전체를 그림 한 장으로 보여 주고 읽는 순서를 알려 줍니다. 부팅, 업데이트, 재구축 안내에도 새 문서를 넣었습니다.
- **RAW 노이즈 감소 검토를 사이트 문서로 옮겼습니다.** Markdown 메모였던 내용을 검수해 [`analysis/raw-nr-feasibility.html`](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/raw-nr-feasibility.html)로 만들었습니다. 결론은 그대로입니다. 조사할 제어 지점을 찾았을 뿐이고, RAW의 노이즈 감소를 끌 수 있다는 근거는 아직 없습니다.
- **세 기종 연구 본부를 읽기 쉽게 바꿨습니다.** 기종별 카드를 한 줄에 하나씩 놓고, 긴 본문은 목록으로, 근거 문서 목록은 접이식으로 바꿨습니다.
- **모든 문서의 문장을 다듬었습니다.** 한국어 윤문 규칙에 따라 연결어미 뒤 쉼표를 빼고, 긴 문장을 나누고, 에두른 표현을 직접 서술로 바꿨습니다. 수치·주소·코드는 바꾸지 않았고, 고친 문단마다 기계로 확인했습니다.
- **첫 화면과 용어집을 갱신했습니다.**

모두 94쪽, 그림 181개입니다. 기존 문서의 파일 이름과 주소는 그대로입니다.

## Lightroom 색 프로파일은 넣지 않았습니다

연구가 Lightroom용 카메라 색 프로파일을 낼 만큼 진척됐는지 검토했습니다. 아직 아닙니다. 그래서 이 릴리스에 색 프로파일은 없습니다.

- 펌웨어에서 꺼낸 값으로 만든 프로파일이 없습니다. 펌웨어의 색 행렬을 프로파일이 쓰는 형식으로 바꾸는 방법을 아직 모릅니다.
- 지금 있는 시험 프로파일은 공개 RAW 파일에 카메라가 적어 둔 행렬을 옮긴 것이고, K-3 II에는 차트 한 장으로 맞춘 톤 곡선이 더해져 있습니다.
- 실제 Lightroom에서 카메라 JPEG와 비교하면, Adobe가 Lightroom에 넣어 둔 카메라 매칭 프로파일이 더 가깝습니다. K-3 II는 1.786 대 1.620(차트), 4.057 대 3.948(다른 장면)이고, K-3 Mark III는 2.028 대 1.421입니다(ΔE00, 작을수록 가까움).
- Q7에서는 시험 프로파일이 Adobe Standard보다 가까웠지만(2.211 대 2.803), 장면 한 장의 일부 영역에서 얻은 값이고 두 결과의 화이트밸런스도 달랐습니다.
- 기종마다 장면 한두 개, 조명 하나로만 쟀습니다. 표본을 찍은 펌웨어도 분석한 버전과 다릅니다. 연구가 스스로 정한 통과 기준(따로 찍은 촬영 쌍, 여러 조명, 미리 정한 허용치)을 아직 채우지 못했습니다.

`profiles/` 폴더의 K-3 II 톤 후보 파일은 실험 기록입니다. 정확한 색을 얻으려고 설치할 프로파일이 아닙니다. 자세한 근거와 다음에 필요한 일은 [Lightroom 색 프로파일 안내](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/guide-lightroom.html)에 있습니다.

## 검수에서 고친 것

수치·주소·해시는 근거와 거의 모두 맞았습니다. 주로 뒤 문서가 이미 해결했는데 앞 문서에 남아 있던 서술을 고쳤습니다.

- `ui-port-contract.html`: "글자의 표면 복사는 미확인"이라던 현황을 고쳤습니다. 글자 비트맵 생성과 합성 표면 전송은 원본 코드로 실행한 항목입니다.
- `stubby-load-auth.html`: "간접 호출의 대상을 확인하지 못했다"는 서술을 고쳤습니다. ROMFS 시험에서 그 호출을 원본 코드로 실행했습니다.
- `update-bank-selection.html`: 지워져 있던 한계 문장("수정한 이미지가 받아들여지거나 부팅된다는 증거가 아닙니다")을 되살렸습니다.
- Lightroom 문서 여섯 쪽과 README: "색 비교는 K-3 II 사진 한 장뿐", "K-3 Mark III와 Q7은 측정하지 않음" 같은 낡은 서술을 현재 상태로 바꿨습니다.
- `lightroom-composed-tone.html`: 사전 기준을 채우지 못했다는 판정을 요약 맨 앞에 올렸습니다.
- `color-tone-residual.html`: 위치 맞춤 잔차 2.707픽셀을 2.706픽셀로 고쳤고, 톤 보정 뒤에 오차가 커진 패치가 여섯 개라는 사실을 보탰습니다.
- 공개 문서에 들어 있던 작업 도구의 내부 메모 문장을 지웠습니다(`research-program.json`, `research-checkpoint.html`).
- 노이즈 감소 메모의 사용설명서 링크가 다른 쪽을 가리키고 있어 고쳤습니다.
- 페이지마다 따로 넣은 스타일, 어두운 화면에서 보이지 않던 그림, PowerShell 전용 명령을 통일했습니다.

전체 목록, 판단이 필요해 남겨 둔 항목, 근거 JSON에서 발견한 문제는 [`docs/audit/2026-11-second-review.md`](https://github.com/yunhyok/pentax-k3iii-firmware-analysis/blob/main/docs/audit/2026-11-second-review.md)에 있습니다.

## 알아 둘 점

- 검수는 원본 펌웨어 없이 했습니다. 문서가 공개된 근거 JSON·검증기와 맞는지 확인했고, 검증기를 펌웨어에 다시 돌리지는 않았습니다. Lightroom과 Adobe SDK도 다시 실행하지 않았습니다.
- `research-checkpoint.html`이 요약하는 연구 여덟 건은 근거가 아직 공개되지 않아 결과를 검수하지 못했습니다.
- 근거 JSON은 `research-program.json`의 문장만 고쳤습니다. 나머지 불일치는 검수 기록에 적고 그대로 두었습니다.
- 이 저장소에는 여전히 원본 펌웨어, 제조사 코드, 카메라에 넣을 수 있는 펌웨어가 없습니다. 모든 분석은 PC에서 했습니다.
