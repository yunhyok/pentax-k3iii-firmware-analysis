# v0.2.0 — 문서 전면 개편과 내용 검수

연구 결과는 그대로 두고, 문서를 읽기 쉽게 다시 쓰고 내용을 검수한 릴리스입니다. 새로운 분석 결과는 없습니다.

문서: https://yunhyok.github.io/pentax-k3iii-firmware-analysis/

## 문서가 어떻게 바뀌었나

- **주제별로 묶었습니다.** 조사한 순서대로 나열되어 있던 문서 48쪽을 9개 주제(시작하기, 부팅과 저장소, 펌웨어 업데이트 과정, 펌웨어 재구축, RTOS 명령과 셸, 카메라 내부 색 처리, Lightroom 색 프로파일, AF와 렌즈 제어, UI와 화면 자원)로 나눴습니다. 모든 페이지 위쪽에 같은 탐색 줄이 있고, 아래쪽에 같은 주제의 이전·다음 문서가 있습니다.
- **주제마다 안내 문서를 새로 썼습니다.** 부팅, 업데이트, 재구축, RTOS, 색 처리 안내 문서가 전체 흐름을 그림 한 장으로 보여 주고 세부 문서를 읽는 순서를 알려 줍니다.
- **첫 화면을 새로 만들었습니다.** 연구의 네 가지 목표와 현재 위치, 펌웨어 파일의 구성, 문서 지도를 담았습니다. 예전 첫 화면에 있던 기술 내용은 `analysis/firmware-structure.html`로 옮겼습니다.
- **모든 문서를 같은 순서로 다시 썼습니다.** 요약 → 확인한 범위 → 배경 설명 → 본문 → 한계 → 재현 방법 → 출처. 주소·해시·사례 표 같은 세부 근거는 접어 두었습니다.
- **그림을 넣었습니다.** 흐름도, 메모리 배치, 상태 전이, 자료 구조 그림 126개를 본문에 넣었습니다. 모두 문서 안에 들어 있는 SVG라서 오프라인에서도 보입니다. 첫 화면에는 카메라 사진을 실었습니다(Wikimedia Commons, 출처는 `assets/photos/CREDITS.md`).
- **근거의 수준을 표시했습니다.** 결과마다 확인(원본 코드를 PC에서 실행), 정적 분석, 모델, 미확인 가운데 어느 것인지 같은 색과 이름으로 표시합니다.
- **용어집을 만들었습니다.** 세 기종 문서에 나오는 용어를 `glossary.html` 한 곳에서 설명합니다.
- **배경 설명과 외부 자료를 보탰습니다.** 리코의 제품 자료와 사용설명서, 공개 소스, 리눅스 커널, DNG 규격 등 1차 자료를 확인하고 링크했습니다.

기존 문서의 파일 이름과 주소는 바뀌지 않았습니다. 새 문서는 7쪽입니다(안내 문서 5쪽, 펌웨어 구조, 용어집).

## 내용 검수에서 고친 것

수치·주소·해시를 근거 JSON과 검증 스크립트에 대조하고, 외부 사실을 1차 자료로 확인했습니다. 주요 정정은 다음과 같습니다.

- Q7의 색공간 메뉴 위치를 "커스텀 E3"으로 적은 곳을 "커스텀 설정 C3"으로 고쳤습니다. PDF에서 글자를 뽑을 때 생긴 오류였습니다. `ui-port-contract.json`과 `research-program.json`도 고쳤습니다.
- 압축 스트림 뒤 280바이트를 "용도를 확정하지 못함"이라고 한 서술을 고쳤습니다. 버전 레코드 표 256바이트와 꼬리말 24바이트입니다.
- `color-algorithms.html`에 남아 있던 "이벤트 bit 2"를 "마스크 0x2 (bit 1)"로 고쳤습니다.
- `pipeline-report.html`의 누적 집계에서 서로 다른 두 시험이 한 이름으로 적혀 있던 것을 구분했고, 근거 집계를 현재 값으로 바꿨습니다.
- Lightroom 문서 여러 곳에 "아직 측정하지 않았다"로 남아 있던 서술을 현재 상태로 바꿨습니다. 시험 프로파일 적용과 TIFF 출력은 세 기종 모두 했고, 색차 실측은 K-3 II RAW 한 장에 대해 했습니다.
- 그 밖에 AF·업데이트·타이머 문서의 조건 서술 여섯 곳을 검증 스크립트에 맞게 고쳤습니다.

전체 목록, 판단이 필요해 남겨 둔 항목, 근거 JSON에서 발견한 문제는 [`docs/audit/2026-11-review.md`](https://github.com/yunhyok/pentax-k3iii-firmware-analysis/blob/main/docs/audit/2026-11-review.md)에 있습니다.

## 알아 둘 점

- 검수는 원본 펌웨어 없이 했습니다. 문서가 공개된 근거 JSON·검증 스크립트와 맞는지 확인했고, 검증 스크립트를 펌웨어에 다시 돌리지는 않았습니다.
- 근거 JSON은 두 파일의 표기 오류만 고쳤습니다. 검수에서 찾은 나머지 불일치는 기록만 하고 그대로 두었습니다.
- 이번 개편에서 배경 설명으로 넣은 외부 규격·공개 소스와의 비교는 본문에 "확정한 것이 아님"이라고 적었습니다. 목록은 검수 기록에 있습니다.
- 이 저장소에는 여전히 원본 펌웨어, 제조사 코드, 카메라에 넣을 수 있는 펌웨어가 없습니다. 모든 분석은 PC에서 했습니다.

## 도구

- `assets/site.css`: 세 저장소가 함께 쓰는 스타일시트. 밝은 화면과 어두운 화면, 인쇄, 좁은 화면을 지원합니다.
- `site-map.json`, `tools/site_chrome.py`: 문서 지도와, 그것으로 모든 페이지의 탐색 줄을 채우는 도구.
- `tools/check_site.py`: 모든 페이지의 구조, 내부 링크와 앵커, 탐색 줄이 최신인지 검사합니다. CI와 릴리스 작업이 실행합니다.
- `.github/workflows/release.yml`: `docs/releases/<버전>.md`가 main에 들어오면 검사를 돌린 뒤 릴리스를 만듭니다.

## 내려받기

`pentax-k3iii-firmware-analysis-v0.2.0.zip`에 저장소 전체가 들어 있습니다. 압축을 풀고 `index.html`을 브라우저로 열면 됩니다. `SHA256SUMS.txt`로 파일을 확인할 수 있습니다.
