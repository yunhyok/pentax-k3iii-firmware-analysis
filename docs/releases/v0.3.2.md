# v0.3.2 — 세 기종 연구 인계와 후속 검토 요약

v0.3.1 이후 독립 검토를 마친 로컬 연구 8건의 요약과 다음 과제를 포함합니다. 원본 검사기·SDK·실행 기록의 전체 공개 패키지는 아직 준비 중입니다. 요약에 기록한 해시는 로컬 근거를 식별하며, 요약만으로 결과를 재현할 수 있다는 뜻은 아닙니다. [연구 인계](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/research-checkpoint.html)

- Q7은 원본 Adobe DCP를 SDK 공개 API로 파싱하고 다섯 백색점 XY에서 표를 선택했습니다. 반환 40,500개 성분을 독립 계산과 대조했습니다. 별도의 고정 가중치 실험과 native 참조 픽셀 실험도 구분해 기록했습니다. 전체 RAW·Lightroom 색 일치는 미검증입니다.
- K-3 III AF는 D9 객체 등록에 성공한 조건에서 ReloadTimer의 32비트 카운터 읽기로 이어지는 정적 경로를 확인했습니다. 객체 등록·IRQ 등록과 실제 초기화 순서는 구분하며, 장치 I/O를 실행하거나 시간 단위를 확정하지 않았습니다.
- K-3 III의 추가 RMW 워드와 K-3 II 톤 필드 저장·복원은 제한된 모형·분리된 원본 구간의 결과로 정리했습니다. 로드맵의 초기 “빌드 미착수” 표현을 부분 재컴파일 완료·실기 미검증 상태에 맞게 수정했습니다.

네 목표의 근거와 다음 검증은 [연구 본부](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/research-program.html)에 있습니다. K-3 II와 Q7의 개별 공개 재현 패키지는 각 저장소의 v0.3.1을 유지합니다. 기존 릴리스 태그와 ZIP은 변경하지 않았습니다.

이 ZIP은 분석 코드와 문서입니다. 수정 펌웨어의 카메라 수용·부팅·복구, 최종 색 일치, 렌즈 구동 변경과 UI 이식은 완료되지 않았습니다. 원본 펌웨어·상용 DCP 전체 표·SDK 전체 소스·실행 바이너리·카메라 설치용 이미지는 포함하지 않습니다. ZIP은 함께 제공하는 SHA256SUMS.txt로 확인할 수 있습니다.
